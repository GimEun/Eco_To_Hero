# 작업: 사이트만 전환의 타 맵 비교

- 상태: 완료 — 2026-11-12 (사용자 일괄 승인, 실제 미적용 유지)
- 구현 관련 파일: 기존 `attack-switch-*` 훅·정책 검사, 이번 집계·동결 명세

## 요청 사항

- 사용자의 다음 작업 진행 지시에 따라 사이트만 전환의 다른 맵 비교를 수행한다. 이미 구현한 진단 정책을 재사용하는 최소 범위로 중계소/화물 창고 초기 명단 각 12경기를 추가한다.

## 진행 현황

- [x] 비교 범위 기록 — 새 24경기, 기존 48경기 재사용, 합계 72조건
- [x] 조건·코드·입력 결과 동결 및 문법 확인 — 22파일 SHA-256·집계/동결 도구 문법 통과
- [x] 두 맵 추가 계산·정책/대조군 검증 — 새 24경기·422라운드 모두 정상 종료
- [x] 3맵 비교 결과와 다음 범위 정리 — 총 72조건·1,310라운드, 목표 미달·실제 미적용

## 주요 결정

- 08과 같은 알려진 6시드·양 진영·초기 명단이며 범위 46~54/상대 공격 대체·지원 우선 우회·기존 구매를 유지한다. 새 AI 판단은 추가하지 않는다.
- 비교는 사이트만 대 둘 다, 연구소 두 조건 24경기와 타 맵 둘 다 24경기를 재사용한다. 새 시드 독립 검증이나 보강 검증으로 취급하지 않는다.
- 다음 작업 진행 지시는 기존 진단 정책의 타 맵 비교를 수행하는 범위로 해석한다. 실제 평가 정책 변경·게임 적용까지 승인받은 것으로 해석하지 않는다.

## 결과

| 맵 | 현행 전술·사이트 전환 | 사이트만 전환 | 같은 짝의 승패 개선/악화 |
|---|---:|---:|---:|
| 중계소 | 7/12 | 7/12 | 0/0 |
| 화물 창고 | 6/12 | 7/12 | 1/0 |
| 연구소 | 3/12 | 5/12 | 2/0 |
| 합계 | 16/36 (44.4%) | 19/36 (52.8%) | 3/0 |

- [전체 집계](site-maps-summary.json), [동결 명세](site-maps-freeze.json). 평균 전체 라운드 득실은 -2.83→-1.67, 승리 평균 점수 차이는 7.31→6.42라운드, 4라운드 이내 승리는 6/16→9/19다. 중계소 승리 평균 차이는 8.43→8.71로 오히려 커져 모든 맵 접전 개선으로 일반화하지 않는다.
- 같은 시드/맵/시작 진영에서 패배→승리는 3건, 승리→패배는 없었다. 개선은 창고 1·연구소 2경기이며 중계소는 승패가 전부 같다. 이 알려진 표본에서 사이트만이 더 나았다는 관측이며 새 세계에도 보장되는 규칙은 아니다.
- 현재 후보의 초기 고정 운용은 기존 12/36(33.3%)로 바뀌지 않는다. 사이트만의 52.8%도 반응형 목표 55~65% 아래다. 기존 후보를 통과 처리하거나 사이트 전환만으로 밸런스가 해결됐다고 하지 않는다.
- 정책별 자신의 과거 연패로 변경 299건을 검증했고, 첫 공격 전환 이전의 대조 기록 447라운드 완전 일치를 확인했다. 72조건 완결성·점수·MR12 종료·경제·지원/우회 제한·동결 22파일·실제 소스 107파일 해시 보존 검사를 통과했다. 신규 두 프로세스는 I/O 재시도 없이 정상 종료했다.
- `node --check`로 새 집계·동결 도구 2개 문법 통과, `node summarize-site-maps.mjs` 실행 검사 통과. 재사용 훅/정책은 변경하지 않아 이전 4개 검사를 반복하지 않았다. 실제 화면 변경이 없어 Vite 빌드·브라우저 검사는 생략했다.

## 다음 작업

- 사이트만 공격 전환을 후속 진단의 주 평가 정책으로 채택할지 확정한 뒤, 알려진 시드에서 초기 고정/해당 반응형의 상대 능력·전술 후보를 비교한다. 실제 게임 규칙 변경이나 보강 상한 재도입은 제안하지 않는다.
- 실제 평가 정의를 바꾸는 결정과 게임 적용은 이번 비교에 포함하지 않았다. 후속 후보 선정 후에만 동결된 새 시드 검증을 진행하며 앞선 실패는 유지한다. 진단 종료와 밸런스 1번 전체 완료는 구분한다.

## 사용자 작업

- 실제 웹페이지 미변경의 Node 진단이다. 화면 확인은 필요하지 않다.
