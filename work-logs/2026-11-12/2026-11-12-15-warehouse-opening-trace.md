- 상태: 완료 — 2026-11-13

- 구현 관련 파일: 이번 관측/메모리 훅/집계 도구, 기존 진단 훅과 경기 원자료

## 주요 결정

- 새로운 후보/시드/AI 판단/실제 게임 변경은 없다. 기존 12경기 재현이며 신규 독립 표본으로 세지 않는다.
- 실제 전투 처리 직전에 현재 시야와 사격 가능 표적을 읽기만 한다. 난수는 호출하지 않고 관측 상태는 게임 state 밖 WeakMap에 둔다. 전투 후에는 실제 발사/사망 이벤트를 복사한다.
- 첫 시야는 시뮬레이션의 프레임별 사격 단계에서 관측한 최초 시야다. 연속 시간 전체의 수학적 최초 접촉이나 팀 전체에 정보가 전달된 시간과 같다고 단정하지 않는다.
- 전체 경기 결과에서 관측 필드만 제거한 기록을 과거 원자료와 완전히 비교해 관측이 경기 행동을 바꾸지 않았는지 검사한다.

## 결과

- [관측 결과](opening-engagement-summary.json), [관측 코드](opening-engagement.mjs), [집계](summarize-opening-engagement.mjs), [동결](opening-engagement-freeze.json).
- 관측 필드만 제거한 12경기 전체 결과가 원자료와 완전히 동일했다. 모든 라운드의 장비·통계·승패·전환·이동 추적도 포함한 비교다. 새 독립 표본이나 새 후보 실험은 0건이다.

- 수비의 최초 시야는 standard 124틱·forward 99틱, 공격은 각각 128틱·105틱이었다. 수비가 0.20/0.30초 먼저 봤다. 다만 실제 무기 사거리까지 충족한 최초 표적은 양 팀 모두 standard 140틱·forward 122틱이었다. 시야를 먼저 얻었다고 사거리 내 선제 발사를 보장하지는 않는다.
- 최초 발사는 standard 수비 150틱·공격 148~149틱, forward 수비 131틱·공격 130~131틱이었다. 차이는 대부분 1~2틱(0.05~0.10초)이다. 지능에 따른 표적 획득 대기가 코드에 존재하지만 이 작은 차이가 라운드 패배 전체를 유발했다는 증명은 아니다.
- 최초 사망은 12라운드 중 11번 공격수였으며, 모든 라운드가 결국 수비 전멸로 끝났다. 수비가 발사하지 못하거나 첫 사망부터 항상 불리해 전멸하는 상황으로 설명할 수 없다. 12203/forward는 공격수 2명이 먼저 사망했는데도 최종 수비 전멸이었다.
- 시야→표적→발사 간격에는 시야 단절·표적 변경·사거리 변화가 들어갈 수 있다. 평균 표적 획득→첫 발사 간격을 순수 반응속도로 해석하지 않는다. 같은 틱 발사/사망 이벤트의 배열 순서를 세부 시간 우위로 취급하지 않는다.

## 검증·후속 범위

- 관측 검사 3개 통과: 실제 상태/난수 불변, 이벤트 커서 중복 방지·복사본 격리, 첫 수비 라운드 외 비활성. 새 훅/집계/동결 도구 문법 및 실행 통과. 사건별 발사/사망 수가 원 라운드 통계와 일치했고, 동결 42개/실제 소스 107개 해시를 보존했다. 두 재현 프로세스 정상 종료·I/O 재시도 없음.
- 실제 웹 코드 미변경이라 Vite 빌드·사용자 화면 확인은 생략했다. 전체 밸런스 목표는 미달·후보 미적용 상태다.
- 코드 검토에서 `defenseDestination`은 체력 45 이하에서 withdrawn 상태를 설정하고, 지원/앵커 합류보다 후퇴 목적지를 먼저 반환한다. `moveActors`는 교전 중이라도 retreating이면 계속 이동하며, 사격 명중 계산에는 이동 중 감점이 있다. 이는 후퇴/지원 관계를 관측할 구체 후보이지 이번에 후퇴가 패배 원인임을 입증한 것은 아니다.
- 다음은 같은 기존 12경기의 후퇴 구간 관측이다. 매 발사/피격·체력 임계/후퇴 전환 시 체력·이동/후퇴 여부·현재 목적지·근처 지원 가능 아군을 별도로 기록하고, 최초 공격수 사망 뒤 수비 우위가 무너지는 순서를 분석한다. 기존 결정·난수·구매는 바꾸지 않고 관측 필드를 제거한 원 전체 결과 일치를 다시 확인한다. 새 관측은 새 파일로 추가해 현재 동결된 관측/원자료를 수정하지 않는다.
- 이번 작업에서는 후퇴 관측 재현을 아직 실행하지 않았다. 실제 후퇴/지원 판단 변경이 필요하면 근거와 주요 설계를 사용자에게 확인한 뒤 진행한다.
