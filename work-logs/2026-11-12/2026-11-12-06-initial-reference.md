# 작업: 초기 명단 기준의 후보 선정·독립 검증

- 상태: 완료 — 2026-11-12 (사용자 일괄 승인, 1번 전체 미완료·후보 미채택 유지)
- 구현 관련 파일: 이 날짜 폴더의 진단 도구·동결 명세·결과 집계

## 요청 사항

- 사용자가 재선택한 ‘초기 명단만 목표 적용·보강은 자연 상승’을 기준으로 밸런스 검증을 이어간다.

## 주요 결정

- 초기 명단은 고정 승률 20% 이하·반응형 55~65%를 유지한다. 보강 명단은 같은 AI에서의 짝 비교로 영입 효과를 확인하며 승률 상한을 두지 않는다. 상대를 보강에 맞춰 강화하지 않는다.
- 이전 두 독립 검증 실패는 유지한다. 새 목표로 과거 실패를 성공 처리하지 않는다.

## 진행 현황

- [x] 목표 적용 대상의 사용자 승인 기록
- [x] 기존 알려진 후보를 새 기준으로 비교하고 한 후보 동결 — 46~54/공격 대체, 초기 고정 3/18·반응형 11/18
- [x] 새로운 미사용 시드의 독립 검증·영입 짝 비교 — 144경기·2,741라운드, 제외/대체 시드 없음
- [x] 결과·실제 적용 가능 여부 정리 — 초기 두 목표 미달로 미채택, 실제 게임 미변경

## 사전 검증 정의

- 기존 05의 네 후보만 재비교한다. 초기 두 승률의 목표 구간 밖 거리 제곱합, 초기 반응형 승리 점수 차이, 기존 후보 순서로 하나만 선정한다. 과거 독립 검증에서 실패한 후보를 그대로 다시 채택하지 않는다.
- 접전은 승리 평균 점수 차이와 4라운드 이내 승리 수를 보고한다. 합의되지 않은 수치 합격선을 임의로 만들지 않으며 승률 통과만으로 접전까지 검증됐다고 하지 않는다.
- 새 시드는 18313/19319/20323/21341/22343/23371이다. 기존 JSON의 seed/seeds 기록에 없는지 확인한 후 세계 생성 전에 명세를 동결한다. 보강 불가 시 제외 사유를 기록하고 대체하지 않는다.
- 실제 구매·경제·선수·저장은 유지한다. 기존 지원 우선 우회와 반응형 운용 정책을 재사용한다. 새 AI 판단은 추가하지 않는다.
- 보강 효과는 같은 시드·맵·진영·운용끼리 승수와 평균 라운드 득실의 변화를 보고한다. 보강 후 매 경기 승리나 순수 단일 능력 효과를 보장하는 검사는 아니다.

## 구현 내용

- [동결 명세](independent-initial46-freeze.json)는 세계 생성 전 6시드의 기존 JSON seed/seeds 사용 이력 부재와 후보 선정을 검사하고 코드·기존 선택/집계 10개 파일을 SHA-256으로 고정했다.
- [선정 도구](freeze-initial-reference.mjs), [집계 도구](summarize-initial-reference.mjs)는 문법 검사를 통과했다. 기존 전체 검증 도구를 재사용해 조건·연패 변경·경제·경로·소스 보존을 확인하며, 별도 새 기준 결과에서만 보강의 목표 판정을 제외한다. 과거 결과·동결 코드는 수정하지 않는다.
- 재귀 JSON 이력 검사에서 UTF-8 BOM이 있는 이전 자료를 만나 첫 시도가 중단됐다. 새 도구의 읽기에서 BOM을 제거하고 재실행해 정상 동결했다. 세계 생성 전 오류이며 시드/후보를 변경하지 않았다.
- 세 맵을 별도 Node 프로세스로 계산한다. 실제 브라우저 코드 변경이 없어 Vite 빌드·웹페이지 사용자 검사는 이번 진단에서 생략한다.

## 독립 검증 결과

| 명단 | 고정 운용 | 반응형 운용 | 판정 |
|---|---:|---:|---|
| 초기 | 12/36 (33.3%) | 16/36 (44.4%) | 두 목표 모두 미달 |
| 보강 | 12/36 (33.3%) | 17/36 (47.2%) | 승률 상한 없이 영입 효과 비교 |

- [새 기준 결과](initial-reference-result.json). 6시드 모두 합법 보강이 가능했다. 동일 조건 36쌍에서 평균 라운드 득실은 고정 +1.53·반응형 +1.56 개선됐다. 고정 승수는 그대로이며 반응형은 한 승 증가해 큰 승률 개선을 입증하지는 못했다.
- 초기 반응형 승리 평균 점수 차이 7.31라운드, 4라운드 이내 승리는 6/16이다. 접전이 충분해졌다고 판정하지 않는다.
- 초기 명단의 맵별 고정→반응형 승수는 중계소 5→7/12, 창고 2→6/12, 연구소 5→3/12다. 반응형에는 전술·사이트 전환 외 장비 구성 차이도 포함되므로 연구소 패배를 전환 하나의 인과 효과라고 단정하지 않는다.
- 고정 조건부터 목표를 넘겼고 반응형은 목표 아래라, 이 후보를 단순 하향해 적용하거나 새 시드를 대체해 재검증하지 않는다. 다음은 기존 경기 기록에서 연구소의 운용별 교전·설치·장비·전환 차이를 분석해 원인을 좁히는 작업이다. 새 판단 규칙이 필요하면 그때 주요 설계를 확인한다.
- 반응형 변경 294건·조건 완결성·경제·우회 제한·지원 우선·동결 10파일·실제 소스 107파일 SHA-256 동일 검증 통과. 세 프로세스 정상 종료. 창고 결과 저장의 일시적 EPERM은 기존 보조 도구로 1회 재시도 후 성공했으며 경기 재실행은 없었다.
- `summarize-independent44.mjs`가 생성한 이번 이름의 `independent-initial46-summary.json`은 기존 네 구간 판정을 포함하는 공통 검증 중간 산출물이다. 현재 목표 판정은 보강 판정을 제외한 `initial-reference-result.json`을 따른다. 이전 44/48 검증 결과는 수정하지 않았다.
- 실제 게임·선수·저장 미변경, 후보 미채택. 이 검증의 종료를 1번 밸런스 전체 완료로 처리하지 않는다.
