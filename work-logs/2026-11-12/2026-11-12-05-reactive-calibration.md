# 작업: 반응형 평가 기준의 능력·상대 전술 후보 비교

- 상태: 완료 — 2026-11-12 (사용자 일괄 승인, 독립 검증 미달 결과 보존)
- 구현 관련 파일: 기존 진단 도구·우회 훅과 이 날짜 폴더의 집계 도구

## 요청 사항

- 승인된 반응형 포함 평가 틀로 잔여 밸런스 조정을 이어간다. 실제 게임 변경은 검증된 후보가 정해진 후 진행한다.

## 진행 현황

- [x] 평가 정책·시드·후보 범위 사전 고정
- [x] 알려진 시드의 후보 비교 및 행동/대조군 검증 — 새 288경기·5,808라운드 및 변경 679건·중단 전 24행 재생 일치
- [x] 한 후보를 고정해 새 미사용 시드로 독립 검증 — 108경기·1,988라운드 완료, 목표 미달
- [x] 결과 및 실제 적용 가능 여부 정리 — 실제 적용 보류, 독립 결과를 바꾸지 않음
- [x] 다음 목표 적용 대상 결정 — 사용자 최종 재선택으로 초기 기준·보강 자연 상승 승인. 이 작업의 기존 독립 실패는 유지하고 06에서 새로 검증한다.

## 사전 비교 정의

- 운용 정책은 04에서 정의한 고정/반응형으로 고정한다. 맵별 시작 선택은 기존 risk-training/selected-choices.json이다. 내 구매 legacy·상대 mixed·기존 6연패·지원 우선 우회, 실제 경제/선수/저장은 유지한다.
- 알려진 비교 시드는 73/101/211이며 초기/비감소 보강·3맵·양 진영·고정/반응형 각 후보 72경기다.
- 비교는 44~54/current(04의 72경기 재사용), 46~54/current, 48~54/current, 46~54/attack-alternative, 46~54/defense-alternative의 다섯 개다. 44~54는 이전 독립 검증의 동일 고정 조건이 이미 실패했으므로 **기준선으로만 보존하고 재채택 후보에서 제외**한다. 새 평가 이름으로 과거 실패를 지우지 않는다. 기존 도구의 초기 전술만 바꾸며 새 판단 규칙은 추가하지 않는다. 네 새 후보 합계 288경기를 실행한다.
- 선별은 네 목표 구간 밖 거리의 제곱합이 작은 후보, 동률이면 반응형 승리 평균 점수 차이가 작은 후보, 다시 동률이면 사전 나열 순서로 하나만 선택한다. 모든 결과를 보존하며 완전 통과로 재분류하지 않는다. 독립 검증 전 후보/정책/코드를 동결한다.
- 새 미사용 최종 시드는 **12203/13217/14243/15263/16273/17293**으로 사전 지정한다. 기존 JSON seed 기록이 없음을 확인한 뒤 아직 세계/결과를 열람하지 않았다. 보강 불가 시 기록하고 대체하지 않는다. 검증 결과를 보고 다른 후보/시드를 소급 선택하지 않는다.
- range46/attack46 실행은 각각 저장 완료 6/16행과 교체 대기 7/17행에서 결과 파일 rename EPERM으로 중단됐다. [I/O 재실행 기록](reactive-calibration-io-retries.json)에 원본/교체 대기 기록을 보존하고 별도 폴더에서 같은 조건으로 재실행한다. 새 공통 진단 I/O 보조 도구는 명시 출력 폴더의 일시적 파일 교체 오류만 재시도하며 게임/평가 정책을 바꾸지 않는다. 이전 독립 검증의 I/O 도구는 기록된 해시 재현을 위해 그대로 보존한다.

## 동결 후 새 독립 검증

- [동결 명세](independent-reactive48-freeze.json)에 한 후보·정책·시드·목표·관련 8개 파일 SHA-256을 저장한 뒤 새로운 6시드 실행을 시작했다. 출력 파일 교체에는 검증된 공통 I/O preload를 사용하며 모델/정책/결과를 변경하지 않는다.
- 알려진 비교 288조건과 별도이며, 이전 정적 기준 44~54 독립 검증 실패를 새 반응형 평가로 바꾸거나 성공으로 재분류하지 않는다.

## 같은 조건에서의 영입 효과

- 초기 36경기와 보강 18경기는 시드 구성이 다르므로 두 전체 승률만으로 영입 효과를 비교하지 않는다. 보강 가능한 동일 3시드·같은 맵/진영/정책의 18쌍을 다시 비교했다.
- 고정은 영입 전 3/18→영입 후 6/18승, 반응형은 4/18→8/18승이었다. 평균 라운드 득실은 각각 +2.89·+4.11라운드 개선됐다. 선수 교체는 ID와 여러 능력도 바꾸므로 단일 능력만의 효과라고 단정하지 않는다.
- [짝 비교 결과](reactive48-paired-roster-summary.json), [재현 도구](summarize-paired-reactive48.mjs). 이 결과로 이번 후보의 기존 목표 미달을 성공으로 바꾸지 않는다.

## 다음 목표 적용 대상 제안 — 이후 승인

- 현재 동일 AI에서 실제 영입 개선이 확인됐지만 초기/보강 모두를 같은 좁은 승률 구간에 맞추는 목표를 유지하고 있다. 관측한 개선 폭을 그대로 유지하면서 두 명단을 동시에 같은 범위에 넣을 수 있다고 이번 자료로 보장할 수 없다. 모든 후보에서 불가능하다는 증명은 아니다.
- **초기 명단만 고정 20% 이하·반응형 55~65% 및 접전의 기준점으로 삼고, 보강 명단은 동일 AI에서 자연스럽게 향상되는지 검증하되 승률 상한을 두지 않는 안을 제안한다.** 실제 능력·돈·구매 규칙을 바꾸거나 플레이어를 따라 상대를 강화하는 보정을 넣는 안이 아니다.
- 이 제안은 주요 난이도 목표의 적용 대상 변경이므로 사용자 결정 전에는 채택하지 않는다. 44~54/48~54의 독립 검증 실패는 모두 그대로 유지하고, 승인 시 새 기준으로 새 후보를 선정·동결한 후 새로운 미사용 시드에서 검증해야 한다. 이번 두 검증 시드를 다시 미사용 검증으로 부르지 않는다.
- 이 작업의 실행은 종료했다. 사용자가 최종 재선택으로 제안을 승인해 [06](2026-11-12-06-initial-reference.md)에서 새 기준 검증을 진행한다. 위 제안 당시의 미승인 설명은 이력이며 현재 재개 기준은 PROGRESS.md다. 실제 게임 적용은 계속 보류한다.
