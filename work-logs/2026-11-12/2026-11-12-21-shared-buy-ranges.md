# 작업: 동일 자동 구매 기준의 낮은 상대 능력 범위 비교

- 상태: 완료 — 2026-11-13
- 완료 승인: 사용자 「지금까지 한 작업 완료 처리」 요청. 진단 실패·미채택 결과는 보존하며 완료를 후보 채택으로 해석하지 않는다.
- 구현 관련 파일: 기존 동일 구매/프로필/사이트 전환 훅, 이번 동결·집계 도구

## 요청 사항

- 다음 작업 지시에 따라 상대 능력 범위30~54·38~54·42~54를 같은 자동 구매와 운용 조건으로 비교한다. 기존48~54 기준선은 재사용한다.

## 주요 결정

- 알려진73/101/211·3맵·양 시작 진영·초기 명단·고정/사이트 전환 운용·양 팀 동일 자동 구매·current 상대 전술을 유지한다. 상대 범위 하한만 바꾼다. 실제 내 선수/경제/저장은 변경하지 않는다.
- 원본 시작 선택과 방어 판단을 쓰며13/14/17 변경은 섞지 않는다. 30~54는 실제 PC방 원본 범위지만 진단 결과를 실제 게임 결과로 대신하지 않는다.
- 새 후보 순서는30·38·42, 기존48을 비교 기준선으로 포함한다. 초기 고정/반응형 목표 구간 밖 거리 제곱합→반응형 승리 평균 점수 차이→이 순서로 한 후보를 순위화한다. 목표 동시 통과는 별도로 보고하고 실패 후보도 보존한다.
- 알려진 세계 탐색이다. 과거 다른 구매/운용 조건의 독립 실패를 성공으로 바꾸거나 새 미사용 시드를 이번에 쓰지 않는다.

- [집계](shared-ranges-summary.json), [동결](shared-ranges-freeze.json). 사전 순위의 1위는38~54이나 고정 상한/반응형 하한을 모두 벗어났으므로 채택 후보는 아니다. 모든 후보의 목표 동시 통과 판정은 실패다.
- 반응형 승리 평균 차이는30/38/42에서 각각10.13/9.29/6.25라운드이며 4라운드 이내 승리는3/15·2/7·2/4다. 접전까지 충분해졌다고 표시하지 않는다.
- 연구소의 고정→반응형 승수는30에서4→3/6,38에서3→1/6,42에서1→0/6이다. 모든 새 범위에서 반응형 시작 선택이 고정보다 낮은 성과였다. 현재 시작 선택이 옛 구매 조건에서 정해진 점과 맞물린 관측이며 모든 반응형/인간 운용이 약하다는 의미는 아니다.
- 새108조건·1,921라운드와 기존36조건·630라운드, 총144조건·2,551라운드를 비교했다. 동일 세계/조건의 정책 비교가 섞였으므로 이를 미사용 독립 표본144개로 설명하지 않는다. 실제 게임 수치는 그대로다.

## 검증·다음 범위

- 새 집계/동결 도구 문법 및 집계 실행 통과. 각 후보36조건 완결성·원 세계 능력으로 재구성한 상대 평균 일치·기타 조건 불변·초기 장비108쌍 동일·정책 변경185건·실제 신규 자동 구매 재구성12,949건·MR12 종료·경제/지원 우선·동결69개/실제소스107개 해시 보존을 확인했다. 기존 도구는 수정하지 않아 기존 검사를 반복하지 않았다.
- 세 계산 프로세스 정상 종료. range30 저장의 일시적 EPERM은 기존 I/O 도구가 각각1회씩 총2회 재시도해 복구했으며 경기 재실행/시드 변경은 없었다. 실제 웹 코드 미변경으로 Vite 빌드·사용자 화면 검사는 생략했다.
- 다음은 단순 중간 수치 재추첨 대신42~54/current에서 시작 전술 후보를 같은 구매 조건으로 비교한다. 42는 새 하한 후보 중 고정 목표를 충족하며48보다 반응형 승수가 높았다. 이는38이 사전 순위1위였다는 결과를 바꾸거나42를 최종 채택하는 결정이 아니라, 고정 성과를 유지한 채 반응형 시작 선택을 점검하는 별도 진단이다.
- known73/101/211·양 진영·초기 명단·사이트 전환·동일 자동 구매·원본 판단을 유지하고, 별도 선택 복사본에서 initial.warehouse.defense만forward, initial.research.attack만execute로 사전 변경한 단일 후보를 본다. 이는13/14에서 관측한 후보 값을 다른 조건에서 재검증하는 것이며 효과를 가정하지 않는다.
- 창고/연구소 반응형 각6조건·총12조건만 새로 계산한다. 중계소 반응형6조건과 고정18조건은 기존42 원자료를 재사용할 수 있다. 새 시작 후보는 계산 전에 두 변경을 함께 고정하며 결과를 보고 맵별로 좋은 쪽만 골라 합치지 않는다. 전체 후보의 초기36조건 결과와 기준선 비교를 제시하되 고정 재사용을 새 경기로 세지 않는다.
- 실제 가격/보상/선수/AI 판단/게임 적용은 변경하지 않으며 새 시드 독립 검증은 아직 진행하지 않는다. 이번 작업에서는 다음12조건을 실행하지 않았다.
