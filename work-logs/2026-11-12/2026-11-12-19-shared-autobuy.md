# 작업: 진단 양 팀 자동 구매 통일 비교

- 상태: 완료 — 2026-11-13
- 완료 승인: 사용자 「지금까지 한 작업 완료 처리」 요청. 진단 실패·미채택 결과는 보존하며 완료를 후보 채택으로 해석하지 않는다.
- 구현 관련 파일: 이번 진단 구매 훅·검사·집계, 16의 기존 원자료/관측

## 요청 사항

- 사용자 승인대로 보상/가격은 유지하고 진단 내 팀도 상대와 같은 기존 자동 구매 함수를 사용해 12조건을 비교한다. 실제 게임·수동 구매 UI·저장은 변경하지 않는다.

## 진행 현황

- [x] 사용자 승인·진단 범위 확인
- [x] 구매 통일 진단 도구·검사·조건 동결 — 검사2개·새 훅/집계/동결 문법 통과·57파일 SHA-256 고정
- [x] 같은 12조건 계산 및 장비/구매/정책 검증 — 12조건·227라운드 정상 종료
- [x] 효과·한계·후속 평가 필요 사항 정리 — 구매 격차 감소/승수 개선 없음, 실제 미적용

## 주요 결정

- 사거리 수정이 없는 원본 방어 판단을 사용한다. 연구소 프로필 변경도 포함하지 않는다. 알려진 6시드·창고·수비 시작·standard/forward·48~54/current·사이트만 전환·초기 선수는 유지한다.
- 내 팀의 진단 legacy 선구매만 생략하고 실제 `startEconomyRound(state, { autoHome: true })`를 호출해 양 팀이 같은 자동 구매 함수를 쓰게 한다. 내 팀 선수별 선호도도 같은 슬롯 번호 규칙을 따른다.
- 변경된 구매를 원자료에서 legacy로 오인하지 않도록 결과의 homePurchasePolicy는 shared-auto로 기록한다. 이 진단에서만 사용하며 이후 평가 기준/실제 게임 변경을 자동 승인으로 간주하지 않는다.

## 구현 내용

- 진단 보정 도구의 내 팀 선구매 루프만 생략하고 실제 `startEconomyRound`에 `autoHome: true`를 전달한다. 실제 경제 모듈은 수정하지 않는다.
- 첫 검사에서 동일 이름의 구매 호출이 진단 파일 안에 두 군데 있어 단일 앵커 검사가 실패했다. 장비 스냅샷 직전의 실제 경기 호출로 앵커를 한정하고 2/2 검사 통과 후 동결했다. 다른 호출이나 경기 로직은 수정하지 않았다.

## 결과

|---|---:|---:|

| 내 팀 3연패 후 권총 외 무기 보유율 | 11/430 (2.6%) | 181/385 (47.0%) |

- [집계](shared-autobuy-summary.json), [동결](shared-autobuy-freeze.json). 수정 후 상대의 3연패 후 권총 외 무기 보유율은 146/275(53.1%)였다. 양 팀 같은 함수를 써도 실제 자금·생존·처치·선호 슬롯별 보유 무기는 달라지며 정확히 같은 보유율을 강제하는 보정은 아니다.
- 같은 경기 짝에서 패배→승리 2·승리→패배 3건이다. 평균 전체 라운드 득실은 +1.25 개선됐지만 승수는 줄었다. 구매 차이는 확인됐으나 이것만으로 패배가 해결되거나 새 방식이 승률을 항상 높인다는 결론은 아니다.
- 초반 장비가 같은 첫 라운드 전체 기록은 12조건 모두 이전과 완전히 동일했다. 첫 라운드 수비 승수도 그대로 0/12다. 자동 구매 변경이 당시 권총/방탄복 첫 교전 문제를 고친 것은 아니다.
- 새 12조건·227라운드와 기존 12조건·228라운드, 합계 24조건·455라운드를 비교했다. known 6세계·창고·수비 시작·두 시작 수비 전술만의 진단이라 고정/반응형 전체 난이도 목표 판정이나 독립 검증으로 사용하지 않는다.

## 검증·후속 범위

- 검사 2개 통과, 새 훅/집계/동결 문법 및 집계 실행 통과. 주 정책 전환 51건·첫 라운드 전체 12쌍 일치·MR12 종료·지원 우선·동결 57개/실제 소스 107개 해시 보존을 확인했다.
- 사망/자금 초기화 후 구매 전 상태를 정확히 재구성할 수 있는 양 팀 1,571건에서 실제 자동 구매 함수를 호출해 무기·방탄복·잔액·투척물이 관측과 완전히 일치함을 확인했다. 생존 방탄복 내구도 등 불확실한 경우는 이 재구성 검사에서 제외했다.
- 두 프로세스 정상 종료·I/O 재시도 없음. 사거리 수정 훅/연구소 전술 변경은 미사용이며 실제 게임/UI/선수/가격/보상/저장은 미변경이다. Vite 빌드·사용자 화면 검사는 Node 진단만 추가해 생략했다.
- 다음 비교는 양 팀 같은 자동 구매 조건 안에서 고정/사이트 전환 운용을 함께 보는 기준선 진단이다. 48~54/current·known 73/101/211·3맵·양 시작 진영·초기 명단의 두 운용 36조건을 비교한다. 원본 시작 선택·기존 방어 판단을 사용하며 13/14/17 수정은 섞지 않는다. 이번 작업에서는 아직 실행하지 않았다.
- 이 기준선 비교는 전술 효과에서 구매 차이를 빼는 진단의 연장으로, 기존 목표·과거 실패를 덮어쓰거나 실제 평가 정책의 영구 채택/게임 배포를 자동으로 확정하지 않는다. 결과에 따라 후속 후보/검증 범위를 결정한다.

## 사용자 작업
