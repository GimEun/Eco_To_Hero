## 구현 내용

- IndexedDB 1개 슬롯에 창단·정상 가져오기 자동 저장과 수동 저장을 연결하고 메인 메뉴에 이어하기·저장소 다시 확인·JSON 가져오기를 추가했다.
- 구단 화면에서 저장 상태·수동 저장·JSON 내보내기·가져오기를 제공한다. 모든 비동기 작업 중 중복 입력을 막는다.
- 새 구단·가져오기·다른 저장 덮어쓰기는 현재/저장 구단명을 알리는 확인 후 진행한다. 취소·파일 검증 실패 시 현재 구단과 기존 저장은 유지된다.
- 저장 성공은 트랜잭션 완료 후 표시한다. 다른 탭의 변경은 동일 트랜잭션의 리비전 검사로 거부한다. 실패한 창단·가져오기는 현재 창의 구단을 유지하고 JSON 백업을 안내한다.
- 1MB 파일 제한, 저장 스키마 버전·구단·선수 데이터 검증과 허용 필드만 복원하는 처리를 추가했다. 가져온 문자열을 HTML로 실행하지 않도록 표시 경로를 정리했다.
- 코드·테스트·문서를 갱신했고 외부 서버나 추가 라이브러리는 도입하지 않았다.

## 승인 범위

- IndexedDB에 구단 저장 슬롯 1개를 둔다. 외부 서버나 추가 라이브러리를 도입하지 않는다.
- 창단 성공·정상 백업 가져오기 확정 시 자동 저장하고 구단 화면에서 수동 저장을 제공한다. 저장 성공 여부를 실제 완료 결과로 표시한다.
- 시작 시 저장 존재 여부를 확인하고 메인 메뉴의 이어하기로 구단을 불러온다. 저장 실패 시 현재 구단을 메모리에 유지하고 오류·JSON 백업 방법을 안내한다.
- JSON 내보내기·가져오기를 제공한다. 가져오기 파일의 크기·스키마 버전·구단 필드·선수 ID·능력치 등을 검증하고 지원하지 않는 버전이나 잘못된 데이터는 거부한다.
- 새 구단 생성이나 가져오기로 기존 저장을 덮어쓸 때 구단명과 교체 내용을 알리고 확인 후 적용한다. 취소·검증 실패 시 기존 저장과 현재 구단을 보존한다.
- 전체 세계·계약·경기 데이터·여러 저장 슬롯·클라우드 저장은 포함하지 않는다. 범용 저장 어댑터나 종목 플러그인 계층은 만들지 않는다.
