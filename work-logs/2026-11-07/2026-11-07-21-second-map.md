## 주요 결정

- 6b를 2개 작업으로 나눈다. 이번에는 화물 창고 1개와 맵 선택, 다음에는 연구 시설 1개를 추가한다. 두 번째 맵은 긴 중앙 통로·엄폐 구역·외곽 우회로, 세 번째 맵은 짧은 통로·연결 구역을 제안한다. 독자 설계이며 현재 코드 기반 지도를 사용한다.
- 맵별 공격 경로·수비 배치·지원 위치를 판정 데이터 옆에서 정의한다. 현재 attack-tactics.js의 RELAY_ATTACK_SITES, defense-tactics.js의 RELAY_DEFENSE_TASKS와 지원 x/y 고정값이 다른 벽 배치에서 잘못 적용되는 문제를 해결한다.
- 이동·충돌·시야·사격·폭탄·MR12 계산은 재사용한다. 기존 중계소 전술 데이터 값은 유지하고 새 맵에만 별도 경로/배치를 지정한다. 미래용 맵 엔진이나 에셋 시스템은 추가하지 않는다.
- 맵 변경은 해당 맵의 새 연습 경기로 시작하며 점수·구매 자금·누적 기록·수동 경로를 초기화한다. 다른 맵의 수동 좌표를 재사용하지 않는다.
- 사용자가 단계 분리와 위 데이터 이동·새 경기 초기화 범위를 승인했다. 연구 시설은 다음 작업이다.

## 구현 내용

- 24×16칸의 화물 창고를 추가했다. 중앙 통로, 선반·화물 엄폐, 위/아래 외곽 우회로와 A/B 사이트를 같은 벽·경로·시야 좌표 데이터로 표시한다.
- 맵의 tactics에 공격 경유점·설치/경계 위치, 수비 5인 임무·후퇴 위치, 지원 위치와 접촉 구역 분기선을 둔다. 중계소는 기존 값 그대로 relay-tactics.js로 이동했다. 공통 공격/수비 전술 파일에는 선택 이름·설명만 남긴다.
- 공통 공격/수비·교전·충돌·폭탄·MR12 계산은 선택한 맵을 사용한다. 수비 지원·교차 지원에 남아 있던 중계소 x/y와 접촉 구역 분류도 맵 데이터를 사용한다.
- 상단에 연습 맵 선택을 추가하고 제목·지도 접근성 이름을 선택 맵에 맞춘다. 맵 변경은 진행 RAF/스킵/타임아웃을 끝내고 새 경기·초기 자금·빈 기록·수동 경로로 시작한다. 구단 세계·저장 데이터는 변경하지 않는다.
