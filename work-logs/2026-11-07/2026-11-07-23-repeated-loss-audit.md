## 확인 결과

- 승패를 2:13으로 지정한 코드는 확인되지 않았다. 고정 세계 시드·고정 상대·같은 입력이면 같은 결과가 반복된다.
- 상대만 자동 구매하고 내 팀은 수동 구매다. 미구매 시 권총/소총 차이가 커 통제 실험에서는 양 진영 모두 크게 패배했다.
- 동일 능력·양 팀 구매 조건에도 맵/시작 진영 편차가 남는다. 구매로 모든 밸런스 차이를 설명하거나 사용자 실제 2:13을 재현했다고 단정하지 않는다.
- 사용자 브라우저 세계 시드·선수·입력은 확보하지 않았다. 경기 수치·구매 정책·시드 정책은 변경하지 않았다.

## 조사 조건

- UI는 세계 시드를 새 경기마다 그대로 사용하고 같은 리그의 첫 상대를 고정 선택한다. 상대는 시작 시 자동 구매하고 내 팀은 수동 구매다.
- 통제 재현에는 기본 세계 시드 42를 사용한다. 사용자 브라우저에 저장된 실제 세계·경기 입력은 제공받지 않았으므로 사용자 자신의 정확한 2:13 결과를 재현했다고 해석하지 않는다.
