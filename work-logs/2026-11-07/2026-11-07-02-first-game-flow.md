## 구현 내용

- 가제는 src/config/game.js의 title 한 곳에서 변경하며 앱 헤더·탭 제목에 반영한다.
- 메뉴 → 전술형 FPS 선택 → 구단명 입력 → 초기 정보·가상 선수 5인 명단을 제공한다. 하이퍼 FPS와 배틀로얄은 준비 중으로 비활성화했다.
- 구단명은 1~24자이며 앞뒤 공백을 제거한다. 공백뿐인 값·초과 길이는 구단을 생성하지 않는다. 사용자 구단명은 textContent로 출력한다.
- 취소·이전 화면 이동 시 입력 초안을 유지한다. 기존 구단이 있으면 메인 메뉴에서 돌아갈 수 있고, 새 구단 창단 전 교체 안내를 표시한다. 생성 확정 전에는 기존 구단을 교체하지 않는다.
- 구단명·PC방 리그·$15,000·선수별 포지션·에임·지능·체력을 표시한다. 선수 명단은 구단 생성마다 별도로 복제한다.
- CSS·도형만으로 네이비·차콜·파랑·보라 UI를 구성했다. 반응형 배치, 표 가로 스크롤, 키보드 포커스, 오류 알림을 제공한다.
- 상태는 메모리에만 유지한다. 페이지 새로고침 시 초기화되며 저장·경기·훈련·이적·전체 세계 생성은 포함하지 않는다.
- 초기 조사·설계는 사용자 승인으로 완료 처리했고, 총 58팀 결정과 첫 구현 범위를 설계 문서·AGENTS.md·PROGRESS.md에 반영했다.
