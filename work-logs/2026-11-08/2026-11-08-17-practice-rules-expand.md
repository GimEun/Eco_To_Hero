## 구현 내용

- 점수창 내부에 규칙을 펼치는 방식을 native dialog로 바꿨다. 창 상단 닫기 버튼을 고정하고 Esc로도 닫을 수 있어 점수창의 높이 제한/내부 스크롤 때문에 복귀 버튼을 찾기 어려운 문제를 피한다.
- 지도 우측 상단에 ‘화면 크게 ↗’를 제공한다. 확대 시 브라우저 표시 영역 대부분을 지도로 사용하고 같은 버튼은 ‘원래 크기로 ↙’로 바뀐다. Esc도 확대를 해제한다.
- 확대는 보기만 바꾸며 경기 초기화·점수·구매·선수 선택·세계 상태를 변경하지 않는다. 기존 지도 비율과 클릭 좌표 계산을 유지한다. 화면 종료 시 확대/규칙 창과 이벤트 리스너를 정리한다.
- 실제 지도 크기는 현재 지도 영역의 가로/세로 중 제한되는 쪽에 맞춰 비율을 유지하는 CSS 픽셀 크기로 계산한다. 화면 표시 크기와 고해상도 렌더링 크기를 분리해 이전 작은 캔버스 크기가 확대를 제한하지 않게 한다. ResizeObserver도 캔버스 대신 지도 영역을 관찰한다.
