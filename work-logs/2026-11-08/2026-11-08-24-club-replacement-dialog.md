## 구현 내용

- 기존 공용 구단 교체 확인을 native dialog로 표시한다. 같은 확인을 사용하는 새 게임/JSON 교체/저장 충돌 확인에 연결하며 이어하기의 별도 확인은 변경하지 않는다.
- 확인 전 저장/세계 교체를 진행하지 않는다. 취소/Esc는 false로 닫고 현재 구단을 유지한다.
- 저장 작업 중 앱 입력 잠금과 충돌하지 않도록 모달을 #app 밖에 배치한다.

## 사용자 작업

- [ ] http://127.0.0.1:5173/ 새로고침 후 기존 구단이 있는 상태에서 새 게임 → 종목 선택 → 새 구단 창단을 진행한다.
  - 기대 결과: 사이트와 같은 어두운 패널·보라색 시작 버튼, 현재/저장/새 구단 정보와 저장 덮어쓰기 안내가 표시된다.
- [ ] ‘취소 · 기존 구단 유지’와 Esc로 닫고 기존 구단/저장이 유지되는지 확인한다. 다시 창단하면 확인창을 다시 연다.
- [ ] 교체할 준비가 된 상태에서 ‘새 구단으로 시작’을 누르면 기존 흐름대로 새 구단 저장/화면 전환이 되는지 확인한다.
  - 확인 결과: 사용자 작업 대기. 아직 완료 승인하지 않았다.
