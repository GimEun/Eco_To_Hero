## 구현 내용

- 소속 선택 옆에 정렬 기준과 ↑ 오름차순/↓ 내림차순 버튼을 표시한다. 선택된 방향을 강조하고 접근성 이름·툴팁을 제공한다. 작은 화면에서는 줄바꿈한다.
- 초기에는 기존 명단 순서인 기본 순서를 유지한다. 능력 또는 실제 계약금 산식 기준으로 필터된 전체 목록을 정렬한 뒤 30명씩 표시하며 동점은 기존 순서를 유지한다.
- 기준·방향 변경 시 첫 페이지로 이동한다. 소속 필터·페이지 이동·영입 후에도 정렬을 유지하며 새 세계 생성/복원 시 기본 순서로 초기화한다.
- 정렬은 화면 상태다. 선수 원본·저장 스키마·미저장 여부를 변경하지 않는다.

## 사용자 작업

- [ ] 전체 선수 → 선수 소속 옆의 정렬 기준을 바꾸고 ↑/↓를 눌러 값 순서를 확인한다.
- [ ] 다음 페이지와 자유계약/특정 구단 필터에서도 정렬이 유지되는지 확인한다.
  - 실행: 필요하면 `npm.cmd run dev` 후 http://127.0.0.1:5173 접속.
