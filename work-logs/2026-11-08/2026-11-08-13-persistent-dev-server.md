## 구현 내용

- `npm.cmd run dev:start`는 숨겨진 백그라운드 감독 프로세스로 Vite를 실행한다. 터미널 종료와 분리하고 Vite가 종료되면 2초 후 다시 실행한다.
- `npm.cmd run dev:stop`는 정지 신호 파일로 감독 프로세스가 자신이 실행한 서버를 종료하게 한다. PID만 보고 다른 프로세스를 강제 종료하지 않는다.
- `.dev-server/`의 실행 상태·로그는 Git에서 제외한다. 기존 127.0.0.1:5173 주소와 저장 데이터는 유지한다.
- PC가 켜져 있고 감독 프로세스가 실행되는 동안 유지한다. Windows 재부팅/로그인 자동 시작은 등록하지 않았다.
