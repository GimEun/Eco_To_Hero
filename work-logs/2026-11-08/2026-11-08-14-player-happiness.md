## 주요 결정

- 기존 승인 휴식 규칙: 연속 1~7일 행복도 +2/일, 경험치 변화 없음. 8~14일 +1/일, 세 능력 경험치 각각 -2/일. 15일부터 행복도 유지, 경험치 각각 -3/일. 경험치는 0 미만으로 내려가지 않고 기본 능력치는 유지한다. 다른 행동으로 바꾸면 연속 휴식을 끝내고 주차 변경만으로 초기화하지 않는다.
- 사용자 승인: 행복도 0~100·초기 70, 경기 임시 보정 90 이상 +3 / 75~89 +1 / 45~74 0 / 25~44 -2 / 24 이하 -4. 기본 능력·가격·성장에는 영향을 주지 않고 새 연습에 반영한다.
- 사용자 승인: 개인/팀 훈련 첫 7일 행복도 유지, 방송 첫 7일 +1/일. 같은 비휴식 행동 연속 8~14일 -1/일, 15일부터 -2/일. 개인 훈련 세 종류는 별도 행동이며 실제 진행한 날만 계산한다.

## 구현 내용

- 선수별 morale에 행복도·마지막 실제 행동·연속 기간·마지막 수행 날짜를 보관한다. 1주 진행의 성공한 날짜마다 내 소속 주전/후보만 갱신하고 막힌 날짜는 기록·행복도·경험치를 변경하지 않는다.
- 행동 선택 변경이나 취소만으로 기록을 지우지 않는다. 실제 다른 행동을 수행하거나 소속 공백으로 마지막 수행 날짜가 끊기면 새 연속 기록을 시작한다. 주차·연도·저장 복원만으로 초기화하지 않는다.
- 신규·구형 저장 선수는 행복도 70·기록 없음에서 시작한다. 미소속/AI 구단에는 행복도 일별 변화를 적용하지 않는다. 방출·재영입/이적 시 선수의 행복도·기록을 유지해 재영입으로 초기화되지 않게 한다. 영입 전 일반 선수 목록에는 행복도를 표시하지 않는다.
- 명단 아래 능력·경험치 표에 행복도·보정·실제 경기 적용 능력을 표시하고 행동 선택 창에 현재 행복도·연속 행동 및 주별 효과를 표시한다.
- 새로운 경기 actor 생성 시 세 능력에 행복도 보정을 적용하고 1~99로 제한한다. 기본 선수 객체는 변경하지 않아 가격·계약·성장 원본을 보존한다. 기존 경기 도중에는 스냅샷을 유지한다. 체력의 실제 경기 효과는 기존 구현을 유지한다.
- 팀 훈련의 주간 참가·보상 계산은 유지하며 주간 행동 처리 때만 행복도가 변한다. 경기 재시작·스킵·종료 보상은 행복도/행동 기록을 추가 처리하지 않는다.
- 저장 v11에서 v1~v10을 지원한다. 과거 행동에 불이익/회복을 소급하지 않고 행복도 70부터 시작하며 능력·경험치·계약·재정·진행 중 팀 훈련 참가 상태를 보존한다. 현재 버전은 행복도·연속 기록을 엄격히 검증한다.
