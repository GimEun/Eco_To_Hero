## 요청 사항

- 사용자가 승인한 세 단계 중 1번 주간 일정·행동 선택을 요청했다.
- 구단명 옆 1주 진행·선수별 주간 행동·방송·팀 훈련·화면 명칭 변경을 구현한다.
- 후속 수정 요청에 따라 일별 행동 선택은 없애고, 1주 진행을 누르면 행동 선택 창을 연다. 능력별 경험치는 명단 아래 별도 창으로 옮긴다.

## 주요 결정

- 한 번 누르면 7일을 하루씩 자동 계산한다. 계약 조건으로 중단되면 이미 진행한 날은 유지하고 저장 후에도 남은 일수만 이어간다.
- 행동은 개인 세 능력 훈련·방송·팀 훈련·휴식이다. 개인 경험치 +10, 팀 훈련은 세 능력 중 동일 확률로 경험치 +16, 방송 수입은 하루 $30이다.
- 선수 훈련 → 선수 행동 선택, 훈련 목표 → 행동, 맵 연습 → 팀 연습으로 바꾼다. 관전 경기를 반복 실행해 추가 경험치를 지급하지 않는다.
- 행복도·반복 행동·장기 휴식 경험치 감소는 2번, 랜덤 이벤트는 3번에서 구현한다. 승인된 휴식 수치는 후속 문서에 인계하며 이번에는 기존 휴식의 성장 없음만 유지한다.

## 구현 내용

- 구단명 옆 게임 일차·주차·요일과 1주 진행 버튼을 배치한다. 기존 계약 표의 하루 버튼은 제거하고 주간 진행을 안내한다. 1일 차를 월요일로 계산하며 한 번에 현재 요일부터 7일을 처리한다.
- 1주 진행 버튼은 날짜를 즉시 변경하지 않고 native dialog의 선수 행동 선택 창을 연다. 선수별로 주간 행동 하나만 고르고 선택 완료를 누르면 모두의 선택을 검증해 적용한 뒤 7일을 진행한다. 취소/Esc는 선택과 날짜를 반영하지 않으며 다시 열면 현재 저장 상태에서 시작한다.
- 능력/경험치는 주전·후보 명단 바로 아래 별도 패널에서 읽기 전용으로 표시한다. 선택 창에는 경험치 상세 표를 넣지 않는다. 요일별 입력 UI/API는 제거한다.
- 일별 행동은 개인 경험치 10, 팀 훈련은 세 능력 중 동일 확률로 경험치 16, 방송은 경험치 없이 $30이다. 휴식은 현재 성장 없음이다. 최대 능력이 선택되면 팀 훈련은 재추첨하지 않는다.
- 팀 훈련은 actionRandomState를 사용하고 기존 세계/경기 난수와 분리한다. 소속 선수의 계약 마지막 날까지 행동을 처리한다. 계약/금액으로 막히면 실패한 날짜의 보상·경험치·난수는 모두 유지한다.
- 방송 수입을 하루 자금에 반영하고 기존 30일 정산을 유지한다. 방송 입금만으로 급여 지급 주기를 변경하지 않는다. 실제 주간 방송 수입과 능력 상승/만료 건수를 진행 결과에 표시한다.
- advanceWeek는 하루 계산을 재사용한다. 일부 진행 후 중단되면 남은 일수를 보관하며 저장/복원 뒤 재개해 총 7일만 진행한다. 일부라도 진행한 UI 결과는 미저장으로 표시한다. 첫날 차단은 기존 상태를 변경하지 않는다.
- 맵 연습의 내비게이션·제목·관련 안내를 팀 연습으로 변경한다. 기존 경기 계산/조작은 유지하고 관전만으로 주간 경험치·방송 수입·날짜를 추가하지 않는다.
- 저장 v8은 7칸 행동표·전용 32비트 난수·0~6 남은 주간 일수를 검증한다. v7 목표·경험치·날짜·명단·계약·재정을 보존하고 이전 버전은 기존 변환을 유지한다. 이어하기 읽기로 기존 슬롯을 덮어쓰지 않고 명시적 저장 때 v8을 쓴다.
- 기존 v8과 호환하도록 내부 저장 배열은 유지하며 주간 선택 확정 시 7칸에 동일 행동을 넣는다. 경험치·기존 능력은 변경하지 않는다. 일정이 중단돼 있으면 선택한 행동으로 남은 날짜만 진행한다.

## 후속 단계 인계

- 2번은 행복도·반복 행동·장기 휴식이다. 휴식은 사용자 승인대로 연속 1~7일 행복 +2/경험치 변화 없음, 8~14일 행복 +1/세 경험치 각각 -2, 15일부터 행복 유지/각 경험치 -3이다. 경험치는 0 미만으로 내리지 않고 이미 오른 능력은 유지한다. 다른 행동을 하루 하면 연속 휴식을 끝낸다. 주차 변경만으로 초기화하지 않는다.
- 3번은 랜덤 이벤트 15종·선택별 효과/확률·주간 진행 중단/재개다. 현재 1번에는 행복도·이벤트 결과를 적용하지 않았다.
