## 요청 사항

- 확대 화면에서도 라운드 시작·스킵·관전 속도와 장비 구매·경기 내용을 사용할 수 있게 한다.
- 경기 구매를 장비 구매로 바꾼다.
- 추가 배치 요청: 확대 화면은 시작·스킵 조작 바로 아래 경기 점수, 그 바로 아래 수동 전략·자동 전략·장비 구매·경기 내용 버튼을 둔다.
- 최종 배치 정정: 첫 줄은 관전 속도·구매 완료/시작·스킵만, 둘째 줄은 점수만, 셋째 줄은 네 가지 패널 버튼만 표시한다. 경기 규칙·라운드 결과 등은 확대 중 숨긴다.

## 구현 내용

- 지도 단독 확대를 팀 연습 화면 전체 확대로 바꿔 시작·스킵·속도 선택·점수·전술·장비·기록을 같은 조작 요소로 사용한다. 확대용 조작/구매 상태를 별도로 복제하지 않는다.
- 패널 전환 버튼을 공용 상단 툴바로 옮겼다. 선택한 패널을 닫아도 툴바는 남고, 지도는 빈 패널 영역까지 사용한다. 확대 중 열린 패널은 좁은 옆 영역에 배치해 지도 공간을 확보한다.
- 경기 구매 표기는 버튼·패널 제목·접근성 이름 모두 장비 구매로 변경했다. 기존 구매 단계/자금/무기 규칙을 그대로 적용한다.
- 확대 해제는 버튼/Esc를 유지하고 규칙/결과 dialog가 열렸을 때 Esc는 해당 창을 우선 닫는다. 화면 종료 시 확대 상태와 리스너를 정리한다.
- 확대 화면의 세 줄을 속도·시작·스킵 → 점수만 → 패널 버튼 순으로 정렬했다. 모드 선택·초기화·다음 라운드·시계·상태·타임아웃·설정과 점수 외의 경기 패널 요소는 확대 중 숨긴다. 일반 화면 배치는 유지한다.
- 추가 요청으로 폭탄 운반자·설치 제한·폭발까지 남은 시간·설치/해체 진행을 보여주는 라운드 상태는 다시 표시한다. 패널 버튼 아래, 지도 위에 기존 실시간 상태를 사용한다. CSS 변경 후 빌드 통과.
- 후속 위치 요청에 따라 공용 라운드 상태 요소를 지도 제목 영역으로 옮겼다. 일반 화면은 제목 옆 13px, 확대 화면은 제목 아래 16~21px로 표시하고 밝은 금색 글씨·배경·테두리로 강조한다. 긴 내용은 줄바꿈하며 이동 모드에서는 기존처럼 숨긴다. JS 문법·관련 23개 검사·빌드 통과, 실제 가독성은 사용자 확인 대기.
