## 주요 결정 — 사용자 승인

- 스폰서 종류는 기본·방송·경기 승리·선수 출전의 총 4개다. 앞서 제안한 육성/회복/팀 훈련 조건은 채택하지 않는다. 리그 순위 스폰서도 별도 종류로 추가하지 않는다.
- 경기 승리는 현재 시즌 공식 매치 승리로 집계한다. BO3를 2:0 또는 2:1로 이겨도 1승이며 플레이오프를 포함한다. 팀 연습은 제외한다.

| 소속 리그 | 1단계 승수 / 주 수입 | 2단계 승수 / 주 수입 | 3단계 승수 / 주 수입 |
|---|---|---|---|
| PC방 | 2승 / $2,000 | 4승 / $3,000 | 6승 / $4,500 |
| 시 | 3승 / $3,000 | 5승 / $4,500 | 8승 / $6,500 |
| 도 | 3승 / $4,500 | 6승 / $6,500 | 9승 / $9,000 |
| 전국 | 3승 / $6,500 | 6승 / $9,000 | 9승 / $12,500 |
| 세계 | 2승 / $9,000 | 4승 / $12,500 | 6승 / $17,500 |

- 후속 승인으로 계약 방식을 변경했다. 소속 리그 3단계 중 목표를 먼저 계약하며, 달성 전 주 $1,250 / 달성 후 다음 정산부터 단계 금액을 지급한다. 승리/출전 계약 기간은 해당 리그의 현재 시즌 종료까지다. 기존 4주 정액·달성 후 해금 제안은 대체한다.
- 동시 계약은 1개다. 계약 중에는 해당 계약만 표시하고 다른 상품은 숨긴다. 기본은 자동 유지, 방송은 기존 4주 계약이다. 시즌 계약은 시즌 종료 후 재선택하며 승급 시 새 리그 상품을 표시한다. 실제 시즌 종료/승급 처리는 후속 시즌 구현에서 연결한다.
- 기존 기본/방송의 금액과 방송 주간 조건은 유지한다.

## 리그 구조 협의 기록

- 사용자 지정: PC방~전국은 정규 시즌 상대마다 한 매치. PC방 BO1, 시/도/전국 BO3. 승점 상위 4팀이 무작위 4강 후 결승, 모두 BO3.
- 세계는 4팀씩 4개 조에서 상위 2팀 진출. 조 1위 4팀과 조 2위 4팀이 각각 경기해 각 그룹 상위 2팀 진출, 무작위 4강과 결승은 BO5.
- 계산 시 세계 첫 조별리그 BO1 및 다음 단계 각 그룹 BO3 풀리그를 가정했다. 해당 세부 방식·승점·동률·3/4위 결정은 시즌 구현 전 확정이 필요하다. 이번에 시즌 코드는 구현하지 않았다.

## 구현 내용과 범위

- 상품 4종과 소속 리그 3단계 조건/금액, 무작위 지정 선수 제안을 표시한다. 제안은 세계 시드와 명단의 ID로 고정해 동일 명단의 재개방·저장 복원·명단 순서 변경에 흔들리지 않는다. 명단이 바뀌면 계약 전 제안 대상은 달라질 수 있다.
- 방송 계약 후 해당 계약·잔여 주·방송 진행 막대·현재 수입만 표시한다. 4회 정산 후 기본 및 전체 상품 표시로 복귀한다.
- 시즌 계약의 단계·리그·대상·진행도와 정산 당시 계약 스냅샷을 저장 v18로 검증한다. 주간 정산은 시즌 계약을 만료하거나 실적을 초기화하지 않는다. v17 방송 잔여 기간/실적과 과거 재정을 보존한다.
- 공식 시즌이 아직 없어 승리/출전 계약 버튼과 실행 함수는 잠금 처리했다. 종료 불가능한 계약을 만들지 않는다. 화면에 시즌 시작 후 계약 가능함을 표시하며 연습을 공식 실적으로 세지 않는다.
- 공식 매치 결과/선수별 실제 출전 집계, 계약 이전 해당 시즌 실적 반영, 시즌 종료/승급에 따른 만료·제안 갱신은 시즌 작업에서 완성한다. 이번에 가짜 공식 경기나 시즌 진행을 추가하지 않았다.

## 사용자 작업

- [ ] 내 구단 → 구단 재정에서 기본/방송/경기 승리/선수 출전 4종 및 승리/출전 각 3단계가 보이는지 확인.

- [ ] 새 주 시작에 방송 계약 후 다른 상품이 사라지고 잔여 기간·방송 진행도·현재 수입이 보이는지 확인.
- [ ] 방송하는 선수를 지정해 1주 진행 후 정산 수입과 계약 잔여 기간을 확인. 4회 정산 후 전체 상품이 다시 나타나는지 확인.
- 확인 결과: 사용자 확인 대기.
- 후속 사용자 보고: “잘 작동하는데”로 상품 화면의 정상 동작을 보고했다. 요청한 스폰서 2×2 배치도 반영했고 좁은 화면은 1열로 표시한다. 공식 경기/시즌 연결은 별도 후속 범위로 유지한다.
