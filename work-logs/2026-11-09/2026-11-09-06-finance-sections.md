## 구현 내용

- 기본 스폰서 계약을 표시하고 버튼 클릭 시 아래 내용만 전환한다. 재정 요약과 버튼은 각 항목의 공통 상단 영역에 표시한다.
- 후속 요청으로 내부 스크롤과 최대 높이를 제거했다. 항목 버튼 전환은 유지하고 선택한 내용은 아래로 길게 펼쳐 페이지 스크롤로 확인한다. 재정 요약은 공통으로 위에 표시한다.
- 전환 시 DOM을 다시 만들지 않아 입력값을 유지한다. 거래/저장으로 화면을 갱신해도 선택한 항목을 유지하며 새 구단/불러오기에서는 초기화한다.
- 주식 거래 후에는 주식 항목을 열어 해당 제목에 초점을 둔다. 기존 주식 그래프·대출·스폰서·정산 계산과 저장 형식은 유지한다.
