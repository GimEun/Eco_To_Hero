## 구현 내용

- `Image/로고`의 S/C를 포함한 10종×6색, 총 60개를 라디오 선택으로 제공한다. 초기 한 개가 선택되어 있으며 키보드 방향키로 선택할 수 있다. 종류 코드 제목을 제거하고 선택 영역을 넓혀 3열로 표시한다.
- ID만 저장하고 실제 주소는 허용된 이미지 목록에서 찾는다. 로고가 없는 기존 저장은 원래 세계 데이터를 보존하며 시드 기반으로 보충한다.
- 내 로고는 타 구단 신규 배정에서 제외한다. 59개를 섞어 순서대로 배정해 새 세계의 타 구단 57팀은 서로 다른 로고를 쓴다. 기존 저장의 로고는 재배정하지 않는다.
- 별도 난수로 선수·경제·경기 난수를 변경하지 않는다. 기존 저장 형식 v23에 선택적 로고 필드를 보존하며 잘못된 ID는 거절한다.
- 원본 이미지는 변경하지 않고 화면 밖 이미지는 브라우저 지연 로딩을 사용한다.
- 일반 점수판을 좌우 같은 폭의 열로 구성해 제목 너비와 무관하게 로고·점수가 전체 가로 중앙에 오게 한다. 확대 화면에서도 전체 폭 중앙을 유지한다.
- 후속 화면 요청으로 로고 목록에 화면 높이 기준 최대 높이와 내부 스크롤을 적용했다. 제목은 스크롤 영역 밖에 남고, 목록 끝에서 휠 스크롤이 페이지로 이어지지 않도록 했다. 목록은 키보드로도 스크롤할 수 있다.
- 리그·구단 화면의 모든 리그 팀 목록에 이름 왼쪽 38px 로고, 오른쪽 CLUB ROSTER 아래 선택 구단 이름 왼쪽 48px 로고를 추가했다. 구단 선택 시 기존 배정 로고를 함께 표시한다.
