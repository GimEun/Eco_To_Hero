# 작업: 탈락·세계 종료 후 자유 일정과 영입 재개

- 상태: 완료 — 2026-11-14
- 구현 관련 파일: 시즌 달력·주간/공식 경기·스폰서·영입·저장·시즌/구단 화면

## 요청 사항

- 확정 순위와 해당 단계 마지막 정산 후 자유 일정으로 전환하고 영입을 다시 연다.
- 훈련/방송/팀 연습/이벤트·계약 감소·급여는 기존 주간 규칙을 유지한다.

## 주요 결정

- 사용자가 추천 규칙을 승인했다. 세계는 탈락한 단계에서 내 도전을 종료하고 아직 시작하지 않은 다음 단계를 열지 않는다.
- 세계 승리/출전 스폰서는 기본으로 복귀하고 방송 계약은 남은 기간을 유지한다.
- 기존 진행 중 경기/일정은 먼저 끝내며 이미 종료한 저장에도 적용한다. 다음 해 전환·기간 건너뛰기는 후속이다.

## 구현 내용

- `season-calendar.js`: 실제 최종 순위/정산으로 국내 탈락·세계 단계 탈락/최종 종료를 판정한다. 진행 중 공식/주간 일정·이벤트·팀 훈련이 끝난 뒤 `offseason`으로 전환하고 영입 창구를 연다. 종료 근거 없는 자유 일정은 저장에서 거부한다.
- `weekly-official.js`·`calendar.js`·`official-match.js`·`team-training.js`: 자유 일정에서는 새 공식 주간을 만들지 않고 기존7일 행동/계약/급여를 재사용한다. 공식/AI 결정전·정산·팀 훈련 보상 완료에서 같은 전환 처리를 사용한다.
- `sponsors.js`: 종료 시 승리/출전 계약을 기본으로 정리하고 자유 일정의 새 시즌 계약은 막는다. 방송 계약은 잔여 기간을 유지한다.
- `save-data.js`·`validate-world.js`: v41 자유 일정과 v40 이전 완료 저장 전환을 연결한다. 날짜/능력/계약/자금/결과/과거 정산을 소급하지 않으며 중단 일정은 먼저 보존한다.
- `world-groups-screen.js`: 자유 일정·영입 재개·세계 계약 종료를 표시하고 탈락팀에게 새52주 준비를 안내하지 않는다. 기존 구단/영입 화면은 공통 달력 판정으로 상태를 표시한다.
- 기존 ‘순위별 탈락 후 새 BO5를 시작’하던 검사는 승인한 새 동작으로 대체했다. 이미 시작한 BO5의 준결승 탈락은 남은 AI와 정산까지 완료하는 기존 동작을 계속 검사한다.

## 사용자 작업

2026-11-14 사용자의 ‘지금까지 한 작업들 완료처리해’ 지시로 이 작업을 승인·종료했다. 아래 개별 확인 안내는 당시 기록으로 보존하며, 각 항목을 실제 실행했다고 추가 기록하지 않는다.

1. 국내 최종3위 이하 또는 세계 조별/순위별 탈락 후 결정전·정산까지 마치면 내 구단에 `자유 일정 · 선수 영입 가능`이 표시되는지 확인한다. 국내1·2위와 세계 진출팀은 계속 영입이 잠겨야 한다.
2. 자유계약/타 구단 영입이 다시 가능하고 기존 자금·능력·명단 정원 조건이 유지되는지 확인한다.
3. 1주 진행으로 훈련·방송·이벤트·계약·급여가 반영되고 공식 경기 없이7일이 진행되는지 확인한다. 팀 연습도 기존 모드 보상을 유지해야 한다.
4. 세계 승리/출전 스폰서는 기본으로 돌아가고 방송 계약은 잔여 기간을 유지해야 한다. 과거 정산과 완료 결과가 바뀌면 안 된다.
5. 저장/불러오기와 JSON 백업 후에도 상태가 유지돼야 한다. 기존 중단 경기/일정은 먼저 끝내고 영입이 열려야 하며 미시작 세계 상위 단계나 다음 해를 자동 생성하면 안 된다.
