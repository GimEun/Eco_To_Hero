## 구현 내용

- MCP는 전역 `chrome-devtools`를 `npx.cmd -y chrome-devtools-mcp@latest --headless --isolated --no-usage-statistics`로 추가했다. 기존 등록은 없었으며 다른 설정을 덮어쓰지 않았다.
- 현재 세션의 직접 MCP 도구 노출과 별개로, 같은 공식 MCP 1.12.0 서버를 stdio 클라이언트로 연결해 검사한다. 브라우저 프로필은 격리한다. 초기 검증에서 라이브러리 진입점을 실행해 종료된 문제와 최신 도구의 `pageId` 필수 인자를 확인하고 실행기를 수정했다.
- 섬광 투척의 예상 인원 계산은 아군 현재 위치와 팀이 실제 관측한 적만 사용한다. 폭발 이후 실제 효과 판정은 기존처럼 실제 좌표/벽/거리를 사용한다.
- 마지막 관측의 정확한 좌표 기억은 기존 5초를 유지한다. 그 기록이 연막 때문에 가려진 것을 확인하면 해당 연막의 중심/반경/만료 시각만 별도의 위험 구역으로 보관한다. 적 ID/숨은 적의 현재 위치·무기·체력은 추가하지 않는다. 연막이 사라지거나 새 라운드면 제거한다.
- 자동 이동 경로가 위험 연막으로 향하고 가장자리 밖에 접근했을 때 선수·연막별 최대 40틱(2초) 경계 후 기존 이동을 재개한다. 같은 연막에 반복 정지하지 않는다. 경계 상태/사유는 기존 `intent` 표시 및 `smoke-risk-response` 이벤트로 확인한다.
- 현재 교전 표적·후퇴/장비 보존·수동 명령·진행 중 폭탄 행동은 우선한다. 설치 전 잔여 시간이 설치 시간+10초 이하, 설치 후 잔여 시간이 해체 시간+10초 이하라면 경계 대기를 생략한다. 날아오는 수류탄 회피는 기존 이동 처리에서 경계 대기보다 먼저 수행한다.
- 이 단계는 위험 구역 기억과 짧은 경계를 구현한다. 위험도 최적 우회/팀 유틸 공동 진입/소리 추론/예측 사격까지 구현한 것은 아니며 기존 2번의 정보·행동 공백에 대한 최소 대응이다. 기존 1번 난이도 수치를 확정하거나 새 전술/역할 작업을 완료 처리하지 않는다.
- 경기 내 임시 상태만 추가하며 영구 저장 형식/마이그레이션은 변경하지 않았다. 사용자 저장·Paker·능력·장비 가격·리그별 전환·영입 상한은 그대로다. `.git`이 없는 폴더라 Git 비교는 수행할 수 없었다.
- MCP 등록은 [공식 Codex MCP 안내](https://learn.chatgpt.com/docs/extend/mcp)와 [Chrome DevTools MCP 저장소](https://github.com/ChromeDevTools/chrome-devtools-mcp)를 확인했다. 현재 대화의 도구 자동 노출은 확인하지 못했지만 stdio로 같은 MCP 서버의 실제 initialize/tools/list/new_page/evaluate_script 호출을 수행했다. 세션 재시작을 현재 구현의 필수 조건으로 두지 않았다.
