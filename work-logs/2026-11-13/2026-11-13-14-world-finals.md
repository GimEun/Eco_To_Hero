# 작업: 세계 52주 BO5 준결승·결승

- 상태: 완료 — 2026-11-14
- 구현 관련 파일: BO3/BO5 공통 결과·세계 플레이오프·주간/공식 경기·저장·관전/시즌 화면

## 요청 사항

- 순위별 상위4팀의 고정 무작위 BO5 준결승·결승을 52주에 연결한다.

## 주요 결정

- 홈 선택→원정 선택→남은 맵→홈 선택 재경기→원정 선택 재경기. 반복 맵 시작 진영은 반대이며 3맵 선승이다.
- 시리즈 전체 퍼즈3회·시작 주전 고정·완료 맵 저장·기권 시 기존 승리 맵 보존/상대3승을 적용한다.
- 주간 준비/팀 훈련/정산은 한 번, 남은 AI 실제 계산 후 마지막 정산과 세계 스폰서 종료. 상금/출전/실적은 시리즈당1회($500/$200/기권$0)다.
- 우승/준우승/공동3위, 순위별 탈락 공동5위·조별 탈락 공동9위이며 3위전과 다음 해 전환은 포함하지 않는다.

## 구현 내용

- `pc-playoffs.js`·`domestic-season.js`: 기존 결과/검증/대진 생성은 기본2선승을 유지하고 세계 BO5에서만3선승을 사용한다. 기존 맵 선택 후 첫2맵을 반대 시작 진영·별도 고정 시드로 반복한다.
- `world-finals.js`: 고정4강 대진·BO5 완료 맵·최종16팀 공동순위·52주/마지막 정산 검증·정상/파산 경로의 세계 스폰서 종료를 연결했다.
- `world-groups.js`·`weekly-official.js`·`official-match.js`·`calendar.js`: 현재 세계 경기에 BO5를 포함하고52주 준비/훈련 한 번 후 준결승·결승·남은 실제 AI BO5를 처리한다. 결과/상금/출전/실적은 시리즈당 한 번이며 계약으로 정산이 막히면 완료 결과를 보존한다.
- `official-records.js`·`validate-world.js`·`save-data.js`·`sponsors.js`: BO5 명단/영수증·v40 저장/구버전 미생성 상태·세계 계약 종료 후 새 시즌 상품 잠금을 연결했다. 기존 결과/선수/재정과1MB 백업 규칙은 유지한다.
- `main.js`·`practice-screen.js`·`official-exit-dialog.js`·`world-groups-screen.js`: BO5 관전/퍼즈/다음 맵/기권 경고와 맵 반복 순서·대진·최종 공동순위/정산을 표시한다. 다음 해 자동 생성은 포함하지 않았다.

## 검증 기록

- 실제 AI 전체 계산을 제외한 첫8개 검사 중7개 통과. 세계 스폰서9,000달러가 지급되는 상황에서 검사 급여100,000으로는 자금이-10,000 이하가 되지 않아 파산 기대식이 실패했다. 기존 급여/수입/파산 규칙은 유지하고 검사 급여만200,000으로 바꿔 실제 파산을 유도했다. 해당1개 재검사 통과. [첫 검사](world-finals-tests.txt), [수정 검사](world-finals-fix.txt).
- `node --check`: 세계 BO5·관전 화면·세계 시즌 화면 문법 통과.
- 전체 회귀 첫 실행은697개 중665개 통과·관전32개 실패였다. 세계 BO5 전용9개(실제 AI BO5 세 시리즈 포함)와 기존 게임/저장 검사는 통과했다. 실패32개는 관전 테스트용 DOM의 `querySelectorAll` 누락이 같은 원인이었으며 실행 앱의 DOM API를 우회하지 않고 테스트 경계를 보완했다. [전체 첫 결과](world-finals-all-tests.txt).
- 테스트용 DOM을 보완하고 BO5 제목/두 다음 맵 버튼/공유 퍼즈 검사를 추가했다. 관전 화면33/33 재검사 통과. [관전 재검사](world-finals-screen-tests.txt). 최초 실패를 성공한 전체 단일 실행으로 바꿔 기록하지 않는다.
- 시작 전 BO5 맵을 반복 변경할 때 AI 선택에 반복 맵 시드가 섞이지 않도록 선택 후보를 최초3맵으로 제한했다. 맵 선택6회 변경/저장 복원을 포함한 최종 BO5 관련8/8 통과. 실제 AI 전체 검사는 앞선 전체 실행에서 통과했으며 재실행하지 않았다. [최종 BO5 관련 검사](world-finals-final-tests.txt).
- `npm.cmd run build`: 첫 빌드2.19초 통과 후 맵 재선택 수정까지 포함한 최종 빌드1.08초 통과. [첫 빌드](world-finals-build.txt), [최종 빌드](world-finals-final-build.txt).
- 현재 검사 항목은 기존/BO5 회귀665개와 수정 후 관전33개로 총698개다. 관련 재검사로 기존 실패를 해결했으며 수정 후 전체 명령을 다시 실행한 것으로 주장하지 않는다. UTF-8 문서·의도하지 않은 한자/일본어·PROGRESS 두 목록 형식을 확인한다. 브라우저 실제 확인은 수행하지 않았다.

## 사용자 작업

2026-11-14 사용자의 ‘지금까지 한 작업들 완료처리해’ 지시로 이 작업을 승인·종료했다. 아래 개별 확인 안내는 당시 기록으로 보존하며, 각 항목을 실제 실행했다고 추가 기록하지 않는다.

1. 순위별 BO1까지 마친 뒤 내 구단에서52주 행동·이벤트·팀 훈련을 준비한다. BO5 고정4강 대진이 표시되고 같은 준비가 반복되지 않아야 한다.
2. 맵 선택 후 홈/원정/남은 맵/홈 재경기/원정 재경기를 확인한다. 4·5맵의 시작 진영은 같은 맵의 첫 시작 진영과 반대여야 한다.
3. 2승에서는 계속하고3승에서 종료하는지, 2:2면5맵을 진행하는지 확인한다. 같은 시리즈 안에서 퍼즈/주전/완료 맵을 유지하고 결승에서는 새 퍼즈3회로 시작해야 한다.
4. 맵 사이 저장/복원·중간 이탈 기권을 확인한다. 기존 승리 맵은 유지하고 상대3승으로 처리하며 완료 시리즈를 다시 실행할 수 없어야 한다.
5. 최종16팀에 우승/준우승/공동3위·5위·9위가 표시되고 AI 잔여 경기 뒤 마지막 정산/세계 스폰서 종료가 한 번만 반영돼야 한다. 계약으로 정산이 중단되면 재계약 후 결과 재실행 없이 정산만 이어져야 한다.
6. JSON 백업 복원과 기존 국내/조별/순위별 결과 보존을 확인한다. 다음 해는 아직 자동 시작하지 않아야 한다.
