## 확정 기준

| 리그 | 현재 생성 능력 범위 | 현재 영입 상한 | 같은 진영 연패 후 전술 전환 |
|---|---:|---:|---:|
| PC방 | 30~54 | 54 | 6패 |
| 시 | 40~64 | 64 | 4패 |
| 도 | 50~74 | 74 | 3패 |
| 전국 | 60~84 | 84 | 2패 |
| 세계 | 70~94 | 99 | 1패 |

- 능력 범위는 일반 생성 선수의 개별 기본 능력 범위이며 팀 평균이나 승률이 아니다. Paker 등 기존 고유 선수의 별도 처리와 기존 저장 선수는 유지한다.
- 현행 수치를 리그 난이도 기준으로 명시하고, 별도 쉬움/보통/어려움 선택과 경기 중 숨은 능력 보정은 도입하지 않는다. 영입·육성 효과는 유지하며 상대가 내 성장에 맞춰 즉시 강해지지 않는다.
- 시즌 중 AI 성장은 별도 4번, 승강·상위 리그 실제 시즌/맵 밴은 10번에서 연결한다. 이번 3번에서 이를 구현했다고 처리하지 않는다.
- 검증은 5리그 × 3맵 × 양 시작 진영 × 기존 2시드 = 60경기 한 묶음으로 한정했다. 특정 승률 달성은 완료 조건으로 두지 않으며 새 후보 탐색으로 늘리지 않는다.
- 승인된 수치와 동작은 이미 생성/경기 코드에 구현돼 있어 다시 덮어쓰거나 저장을 변환하지 않는다. 리그 구단 화면에서 선택한 리그의 능력 범위·전환 주기·고정 기준을 기존 설명 UI로 확인하도록 연결한다.
- 검증은 고정 초기 주전과 각 리그의 실제 생성 AI 한 팀을 시드별로 비교한다. 두 기존 시드는 73/101이며 A 사이트·내 팀 execute/standard·양 팀 기존 자동 구매를 사용한다. AI만 해당 리그의 실제 전술 전환을 적용한다. 이 비교는 시즌 완주나 리그 적정 육성 명단의 목표 승률 검증이 아니다.

## 검증 결과

- [조건·소스 고정](season-difficulty/freeze.json), [전체 집계](season-difficulty/summary.json). 60경기·876라운드 모두 종료했고 원본 세계 데이터와 실제 선수 기본 능력은 경기 전후 보존됐다.

| 상대 리그 | 초기 내 팀 승수 | 초기 내 팀 능력 평균 | 상대 능력 평균 |
|---|---:|---:|---:|
| PC방 | 9/12 | 43.8 | 41.70 |
| 시 | 1/12 | 43.8 | 53.37 |
| 도 | 0/12 | 43.8 | 64.27 |
| 전국 | 0/12 | 43.8 | 73.30 |
| 세계 | 0/12 | 43.8 | 81.20 |

- 위 승수는 영입·육성하지 않은 초기 명단과 기존 두 세계의 리그별 한 상대를 사용한 기술 통계다. 실제 승급 명단·전체 시즌·모든 상대에 대한 승률이 아니다. 상위 리그 전패만으로 기존 수치를 다시 낮추거나 추가 탐색을 시작하지 않는다.
- 실제 경기에서 발생한 전환은 19건이다. 각 리그 6/4/3/2/1연패 경계와 승리 초기화·공수별 별도 집계·내 팀 명령 보존은 자동 검사에서 별도로 확인했다. 전패/전승으로 특정 리그에서 전환 기회가 없었던 것을 규칙 미검증과 혼동하지 않는다.
- 내 팀 기본 능력만 높인 경우 상대 능력·전환 기준이 그대로인 회귀 검사를 추가했다. 경기 중에도 실제 선수 기본 능력이 변하지 않았다. 기존 저장·선수·Paker·영입 상한·자금·계약 형식은 건드리지 않았다.
- 상위 리그 정규 일정·승강·AI 성장은 이번에 구현하지 않았으며 4번/10번으로 남긴다. 3번에 추가 자동 실험이나 미구현 난이도 선택 화면을 남기지 않는다.
