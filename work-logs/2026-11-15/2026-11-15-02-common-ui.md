## 구현 내용

- 공통 색상·표면·경계·모서리·피드백 시간을 CSS 변수로 관리한다. 네이비 차콜 배경과 절제된 황동색 강조를 사용하고 기본 메뉴의 보라색 그라데이션을 제거했다.
- 공통 메뉴에 크기·획이 같은 SVG 아이콘을 사용하고 선택·호버·클릭·비활성 상태를 구분했다. 키보드용 본문 바로가기와 포커스 표시를 추가했다. 작은 화면의 메뉴는 두 줄로 배치한다.
- 시작 화면은 기존 배너 원본과 실제 이미지 크기 1774×887을 유지하고, 게임 시작 행동과 리그 단계의 위계를 정리했다. 리그·경기·훈련·이적이 준비 중이라는 오래된 안내 문구를 현재 제공 범위에 맞췄다.
- 내 구단은 로고·이름과 날짜·진행 버튼을 나눠 정렬하고 저장 도구, 구단 요약, 밑줄형 탭, 명단 순으로 읽히도록 구성했다. 기존 데이터·조건식·data-action과 이벤트 연결을 유지했다.
- 내 구단 능력치의 불필요한 색상 구분을 제거하고 숫자를 정렬했다. 명단의 기존 성장 정보·판매·주전 교체 조작은 그대로 유지한다.
- 공통 버튼 클릭 피드백, 탭 패널 및 주간 행동·설명·구단 교체 모달의 짧은 등장 효과를 적용했다. 모션 감소 설정에서는 모두 끈다. 모달 종료 효과와 영입·승패·승격·우승·능력 변화 이벤트 연출은 후속 단계에 남긴다.
- 새 라이브러리·외부 폰트·유료 API·시스템 설정 변경 없이 기존 JavaScript·CSS를 사용했다.
