## 구현 내용

- 폭탄 상태는 기존 실시간 텍스트를 유지하며 플레이 화면 헤더 안에 표시한다. 큰 별도 강조 상자와 전체 모드의 추가 행을 제거하고, 작은 창에서는 헤더 내부에서 줄바꿈한다.
- 구매·전략·경기 내용은 기존 버튼으로 필요할 때 연다. 첫 진입은 모두 접어 맵을 넓게 표시하며 사용자가 직접 연 패널은 자동으로 닫지 않는다. 열린 보조 패널 폭도 기존 43%에서 280~360px 범위로 줄였다.
- 일반 모드는 중복 제품 상단바·큰 안내 영역을 줄이고 제목/설정, 관전 조작, 점수판, 전략 버튼, 맵 순으로 압축했다. 전체 모드는 관전 조작과 점수판을 같은 줄에 배치하고 화면 가장자리 여백을 줄였다.
- 퍼즈 잔여 상태와 다음 BO3/BO5 맵 버튼을 전략 도구 줄로 통합해 전체 모드에서도 유지한다. 경기 규칙 버튼도 전체 모드에서 사용할 수 있게 했다. 기존 확대/Esc 복귀와 패널별 선택·장비·기록은 유지한다.
- 캔버스 확대·고해상도 표시·지도 선택 계산은 수정하지 않는다. 확보된 실제 영역에 기존 비율·ResizeObserver로 맞춰 표시한다.
