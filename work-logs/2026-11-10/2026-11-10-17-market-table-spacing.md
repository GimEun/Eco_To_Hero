# 작업: 선수 영입 표 간격·소속 정렬

- 상태: 완료 — 2026-11-10
- 구현 관련 파일: `src/ui/screens.js`, `src/styles.css`

## 요청 사항

- 선수 영입 표의 선수·소속 열이 차지하는 과도한 폭과 가로 스크롤을 줄인다.
- 소속 제목과 자유계약 표시를 같은 기준으로 가운데 정렬한다.

## 진행 현황

- [x] 영입 표 최소 너비·열 배분 및 소속 셀 표시 수정
- [x] 문법·관련 검사·빌드 확인 — `node --check src/ui/screens.js`, 관련 검사 10개 통과, `npm.cmd run build` 109개 모듈 통과
- [x] 사용자 완료 승인 — 이번 요청의 일괄 완료 처리 지시로 종료했다. 추가 개별 화면 검증 결과를 받았다는 뜻은 아니다.

## 구현 내용

- 영입 표의 강제 최소 너비 920px을 해제하고 선수 26%·소속 14%·각 능력 10%·영입 30%로 배분했다.
- 소속 헤더·본문에 같은 클래스를 적용해 가운데 정렬했다. 영입 버튼과 금액은 좁은 화면에서 줄바꿈할 수 있다.

## 사용자 작업

- 확인 결과: 추가 개별 결과는 전달받지 않았으며 사용자 명시적 일괄 완료 처리 승인으로 종료했다.
