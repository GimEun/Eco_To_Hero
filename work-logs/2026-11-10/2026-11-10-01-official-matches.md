## 주요 결정

- 사용자는 완료된 공식 경기 재실행 금지·경기 중간 저장 생략을 선택했다. 중도 이탈·새로고침은 경고 후 동의하면 패배 처리한다. 처음 질문의 ‘미완료 경기 재시작’ 추천안은 채택하지 않았다.
- 사이트 내부 이동은 예/아니오 확인창을 사용한다. 새로고침·탭 닫기의 경고 문구와 버튼은 브라우저가 결정하므로 직접 지정할 수 있다는 약속은 하지 않는다. 실제 이탈 후 복원 시 기권 처리하려면 진행 중인 경기 ID만 영속화하며, 선수 위치·라운드 상태를 저장하는 기능은 만들지 않는다.
- PC방 리그의 맵은 무작위로 결정한다. 상위 리그 맵 밴은 해당 리그 후속 작업으로 남긴다. 대진 시드로 맵·시작 진영을 고정하는 방식을 바탕으로 연결한다.
- 내 경기 종료 후 같은 시즌 주의 AI 경기 3개를 실제 MR12 계산으로 처리한다.
- 모든 경기에 시간 제한 없는 퍼즈를 경기당 총 3회 제공한다는 사용자 요청을 받았다.

## 추가 확정 규칙

- 사용자는 0:13 기권패를 선택했다. 기권 시 진행한 라운드 점수는 유지하지 않는다.
- 일반 일시정지·감독용 타임아웃은 경기 전체 총 3회를 공유하고 연장전에도 충전하지 않는다. 실제 시간 제한은 없고 감독용 타임아웃의 전술 편집은 유지한다. 일반 일시정지에서는 편집을 허용하지 않는다.
- 일반 퍼즈는 이동·교전·폭탄·구매·MR12 연습 및 공식 경기에 적용한다. 감독용 타임아웃 자체의 MR12 제한은 유지한다. 실행 중 탭을 숨기면 잔여 퍼즈가 있을 때 1회 사용해 정지한다. 0회면 추가 정지를 요청하지 않는다. 구매 대기는 퍼즈 사용이 아니다.

## 구현 내용

- `official-match.js`: 대진별 독립 시드/맵/진영·실제 주전 명단·현재 주차 시작 검증·한 주 결과 처리. 경기 화면의 내 팀 home과 원래 대진의 홈/어웨이 점수를 변환한다.
- AI는 기존 MR12/반복 연장 엔진을 사용하고 양쪽 모두 동일한 자동 구매 함수를 호출한다. 짧은 계산 묶음 사이에 브라우저에 제어권을 돌려준다.
- 정규 시즌의 공식 경기 시작과 관전·전술·장비 구매·스킵·확대·종료 복귀를 연결했다. 모드·맵·시작 진영·초기화는 잠그며 목표 사이트는 첫 시작 전 선택 가능하다. 공식 경기에서는 팀 훈련 경험치를 지급하지 않는다.
- 저장 v25: 시작 시 경기 ID만 저장한다. 종료 시 내 결과와 AI 3경기를 복제본에서 계산한 뒤 하나의 트랜잭션으로 저장한다. 저장 실패 시 일부 결과를 원본에 반영하지 않으며, 경기 종료 후 다른 화면으로 이동하면 완료 점수 저장을 재시도한다. 다른 탭의 저장 리비전은 덮어쓰지 않는다.
- 사이트 내부 이동은 기존 다크 UI의 예/아니오 모달로 확인한다. 새로고침·탭 닫기는 기본 브라우저 경고를 사용한다. 실제 재진입 후 이어하기에서 진행 중 경기 ID가 있으면 기권 및 AI 결과를 반영한다. 진행 중 ID가 포함된 JSON 가져오기도 기권 처리한다.
- 완료 결과·기권 표시·순위는 저장/JSON 백업에 포함한다. 공식 선수 통산/KDA·보상·스폰서 실적·실제 주간 날짜 연결은 후속 범위다.
- 관련 자동 검사에서 실제 AI 6경기를 계산하고 결과/기권·중복 방지·주차 전환·저장 왕복·공식 화면 종료 콜백·훈련 보상 분리·공유 퍼즈/연장 무충전을 확인했다. 브라우저 실제 화면과 새로고침 경고 확인은 사용자에게 남긴다.
