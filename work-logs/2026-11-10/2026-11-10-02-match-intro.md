## 주요 결정

- 이번 사용자 요청에 따라 경기장 이미지를 각 공식 경기 시작 연출에도 사용한다. 이전 ‘정규 리그 시작 시에만 사용’ 범위를 이 요청에 한해 확장한다. 시즌 조회 메뉴나 팀 연습에는 표시하지 않는다.
- 경기 시작 ID 저장 후 연출을 표시한다. ESC/클릭은 연출만 건너뛰며 기권으로 처리하지 않는다. 연출 중 실제 새로고침/탭 닫기는 기존 공식 경기 이탈 규칙을 따른다.

## 구현 내용

- 원본 1672:941 비율을 유지해 창 크기에 맞춘다. 큰 파란 전광판의 안쪽 영역에 양 팀 로고·구단명과 VS를 배치했다. 구단명은 HTML 이스케이프하고 로고는 즉시 로딩한다.
- 공식 경기 시작 ID 저장 후 모달 연출을 열고, 3초 타이머·ESC·화면 클릭 중 먼저 발생한 입력으로 종료한 뒤 기존 구매 화면을 표시한다. 연출 중에는 경기 시뮬레이션을 시작하지 않는다.
- 스킵/자동 전환 시 타이머·이벤트·모달을 정리하고 중복 종료를 방지한다. 모달을 지원하지 않는 환경에서는 연출을 생략해 경기 진입이 막히지 않도록 한다.
