## 연간 순차 도전·초기 비시즌 — 2026-11-13 확정

게임 1년은 52주이며 연 1회 PC방→시→도→전국→세계 순서로 도전한다. 어느 단계에서든 탈락하면 그해 공식 도전은 끝나고 다음 해에는 PC방부터 재도전하는 방향이다. 각 리그에 머물며 연 3시즌을 운영하는 이전 제안은 채택하지 않았다.

| 구간 | 연간 주차 |
|---|---|
| 비시즌 | 1~4주 |
| PC방 | 5~12주 |
| 시 | 13~22주 |
| 도 | 23~34주 |
| 전국 | 35~46주 |
| 세계 | 47~52주 |

- 경기 수를 줄이지 않고 국내 각 리그 준결승·결승은 마지막 같은 주에 치른다. 세계는 조별 3주·순위별 리그 2주(한 주 2매치)·준결승/결승 1주로 배치한다. PC방 최종 1·2위는 시 리그로 진출한다. 나머지 상위 진출 기준과 탈락 후 영입 재개 시점은 해당 후속 단계에서 정한다.
- 새 게임의 첫 4주에는 공식 경기 없이 기존 주간 행동·훈련·영입·이벤트·팀 훈련·계약 감소·급여/스폰서 정산을 진행한다. 5주 차 경계의 남은 이벤트·팀 훈련까지 마치면 시즌으로 전환한다. PC방 정규 7주는 새 게임의 5~11주, 플레이오프는 12주에 연결한다.
- 시즌에는 자유계약과 타 구단 선수 영입을 UI/API 양쪽에서 막는다. 시즌 내 휴식·훈련 주에도 영입하지 못한다. 판매·방출·주전 교체·재계약은 기존 조건을 유지한다. 기존 최소 5명 유지 규칙도 바꾸지 않는다.
- 저장 v30은 초기 비시즌/시즌 상태를 보관한다. 기존 저장은 원래 날짜·경기·중단 일정을 유지하며 시즌 상태로 이어간다. 과거 날짜를 되돌리거나 이전 구단에 새 비시즌을 소급하지 않는다.
- 시 리그 플레이오프·도 이상 실제 경기·탈락 후 자유 일정/비공식 경기·다음 해 건너뛰기와 급여/계약 정산·다음 해 PC방 재시작은 **후속 구현**이다. 현재는 달력 주차만 넘어갔다고 미구현된 다음 해 비시즌을 자동 생성하거나 영입을 다시 열지 않는다. [1단계 작업 기록](../work-logs/2026-11-13/2026-11-13-03-preseason-window.md).

## 탈락·세계 종료 후 자유 일정 — 2026-11-14 승인

아래 시즌 도중 규칙과 별개로, 2026-11-14 승인한 자유 일정 전환은 다음과 같다. 국내 최종3위 이하·세계 조별/순위별 최종 탈락·세계 결승 종료 뒤 해당 단계 결과와 마지막 정산이 확정되면 올해 도전을 끝내고 영입을 다시 연다. 국내1·2위와 세계 각 단계 진출팀은 다음 공식 단계를 유지한다. 이미 시작한 경기/일정/결정전/이벤트/팀 훈련은 먼저 끝내고 적용한다.

자유 일정에는 새 공식 경기/미시작 세계 상위 단계를 만들지 않고 기존 주간 훈련·방송·팀 연습·이벤트·계약 감소·급여/스폰서/주식 정산을 유지한다. 세계 승리/출전 스폰서는 기본으로 전환하고 방송 계약은 잔여 기간을 유지한다. 영입 가격·능력 상한·명단 정원·최소5명·자금 부족/계약 만료·파산 규칙은 그대로다. 진행 중이던 세계 BO5는 남은 경기와 마지막 정산까지 마친 뒤 전환한다. 이전의 ‘순위별 탈락 후 새52주 BO5를 열어 남은 AI를 계산’하던 흐름은 이번 승인으로 대체한다.

v41은 `offseason` 자유 일정 상태를 보관한다. 기존 종료 저장에는 날짜/자금/선수/계약/결과/정산을 소급하지 않고 상태와 남은 세계 시즌 스폰서만 정리한다. 진행 중 일정은 보존하고 완료 후 전환한다. 달력 연도가 넘어갔다고 다음 해 대진이나 새 비시즌을 자동 생성하지 않는다. 다음 해 기록 보존/PC방 재시작과 기간 건너뛰기는 후속이다. [자유 일정 작업 기록](../work-logs/2026-11-14/2026-11-14-01-free-schedule.md).

## 다음 해 기록 보존·PC방 재시작 — 2026-11-14 승인

2026-11-14 추가 승인으로 다음 해 전환을 연결한다. 해당 도전 연도 시작에서52주(364일)가 지났고 중단 일정 없는 자유 일정이면 `새해 시작`을 수동으로 누른다. 누른 현재 날짜가 새해1주 차이며 비시즌4주 후5주 차에 기존 PC방8팀으로 재도전한다. 늦게 눌러도 날짜를 되돌리지 않고, 누른 것만으로 계약 감소/추가 급여/훈련/가격 변동을 처리하지 않는다. 이번에는 기간 건너뛰기를 포함하지 않는다.

선수/구단/이름/로고·능력/경험치·운영 자금/계약·코치/시설·대출/주식·행동/이벤트 난수는 보존한다. 새해는 진행할 대진/공식 기록만 새로 만들고 대진/맵 난수를 연도별로 고정한다. 이전 국내/세계 대진·완료 맵·최종 순위·공식 출전/상금은 연도별로 보관하고 시즌 화면에서 조회한다. 누적 공식 기록은 모든 연도를 합산하며 과거 경기를 재실행하거나 보상을 다시 지급하지 않는다.

v42는 연도 번호/시작일/지난 기록을 저장하고 이전 저장에는1년 차·시작1일·빈 보관함만 보충한다. 구버전 날짜/기록/자금은 소급 변경하지 않는다. 장기 보관을 위해 JSON 가져오기/내보내기 한도를32MB로 늘리고 기존 검증은 유지한다. [다음 해 작업 기록](../work-logs/2026-11-14/2026-11-14-02-season-years.md).

## 자유 일정 연말까지 진행 — 2026-11-14 승인

자유 일정의 `연말까지 진행`에서 기존 선수 행동 선택 창을 열고, 선택한 행동을 현재 연도 시작일+364일까지 반복한다. 기존 주간 계산으로 실제 진행한 날짜의 훈련·행복도/피로/컨디션·계약·방송·스폰서·급여·시설 유지비·대출 이자·주식을 반영한다. 연속 행동 불이익을 유지하고 마지막 부분 주는 목표일까지의 날짜만 처리한다. 새해는 직접 시작한다.

선수 이벤트·팀 연습·최소 5명 명단을 유지할 수 없는 계약 만료에서 중단한다. 자동 재계약·이벤트 자동 선택·연습 보상 자동 지급은 하지 않으며 수동 해결 후 `계속 진행`해야 한다. 파산하면 종료하고 취소해도 이미 반영한 날짜·결과는 유지한다. 매주 결과와 중단 상태를 자동 저장하며 새로고침 후에는 자동 재개하지 않는다. v43은 진행 상태를 추가하며 이전 저장의 날짜·자금·계약·기록을 보존한다. [작업 기록](../work-logs/2026-11-14/2026-11-14-03-year-advance.md).

## AI 구단 주간 성장 — 2026-11-14 승인

AI 소속 주전·후보도 실제 날짜 진행에 맞춰 개인 훈련한다. 기본 경험치는 하루10, 선수별 성장 속도80/100/120%를 적용하며 경험치100마다 능력+1이다. 선수별 잠재력과 최대99를 유지한다. 자유계약 선수는 자동 훈련하지 않으며 내 구단 선수는 사용자가 정한 행동만 적용한다.

AI는 주 시작에 피로30 이상이면 한 주 휴식하고, 그 외에는 에임→지능→체력을 순환한다. 휴식은 다음 훈련 순서를 소비하지 않는다. 최대에 도달한 능력은 건너뛰고 모두 최대면 휴식한다. 행복도·연속 행동·피로/회복·고체력의 피로 감소는 기존 선수 행동 규칙을 따른다. AI 코치/시설 구매·급여·자율 영입은 이번 범위에 추가하지 않는다.

일반 주간·공식 일정 준비/정산·자유 일정·연말 진행의 실제 처리 날짜만 반영한다. 관전·새로고침·새해 시작 버튼만으로 추가 성장하지 않는다. v44는 처리 날짜와 AI 주간 행동/다음 훈련 순서를 저장한다. 기존 저장은 능력·경험치·소속·계약·자금을 보존하고 적용일에 새 AI 성장 일정을 시작해 과거 훈련을 소급하지 않는다. [작업 기록](../work-logs/2026-11-14/2026-11-14-04-ai-club-growth.md).

## 상담 기반 공식 경기 요약 — 2026-11-14 승인

내 팀 참가 공식 정규·결정전·플레이오프의 완료 맵마다 실제 출전·KDA·피해/발사/명중·라운드 승패/진영/점수/주요 이벤트·사용 전술/목표 사이트 변경을 요약한다. ADR과 명중률은 저장한 실제 수치로 계산한다. 경기 시작의 행복도/피로를 참고 상태로 기록하고 새로운 심리 수치나 경기 후 자동 효과를 추가하지 않는다.

최근30매치/시리즈의 상세 요약을 연도+경기 ID로 구분해 v45에 저장하고 시즌 화면에서 조회한다. 새해에도 남은 요약을 유지한다. 기존 연도별 대진·점수·출전·상금은 삭제하지 않는다. BO3/BO5 기권은 이미 완료한 맵 요약만 유지하며 미완료 맵과 도입 전 과거 경기의 통계는 만들지 않는다. 팀 연습·AI끼리 경기는 기록 대상에서 제외하며 모든 틱/수동 경로 좌표를 보관하지 않는다. 상담 추첨·쿨다운·대사·효과는 후속 작업이다. ## 상담 판정·저장 — 2026-11-14 승인

상담은 전체 완료 맵의 실제 상세 요약을 확보한 내 팀 정상 BO1 경기 또는 BO3/BO5 시리즈당1회 판정한다. 실제 출전한 현재 소속 선수가 대상이다. 최대4개를60%→20%→10%→5% 순서로 뽑고 한 번 실패하면 종료한다. 실제 첫 처치/멀티킬/설치/해체 후보의 가중치는2, 승패/기존 부정 상태 후보는1이다. 같은 경기에서 선수와 이벤트 종류를 각각 중복시키지 않는다.

상담이 발생한 선수 또는 종류는 이후 정상 공식5경기 동안 제외하고6번째부터 다시 허용한다. 기권은 추첨·쿨다운 경기 수에서 제외한다. 정상 경기의 상세 요약이 없거나 판정 호출을 놓쳤더라도 경기 수는 세며, 과거 상담은 소급 생성하지 않는다. 경기별 난수·고정 후보 근거·추첨 결과와 처리 키로 재접속 재추첨을 막는다.

v46은 판정·대기/답변·후속 상담 상태를 저장한다. 기존 저장의 알려진 경기는 처리 기준으로 보충하고 기본 능력/경험치/자금/주간 난수를 보존한다. 명시적 답변 로직은 기존 행복도·피로만0~100으로 제한하며 같은 답변을 재적용하지 않는다. 후속 상담도 예정 시점·쿨다운·추첨을 지키고, 해당 선수가 떠나면 예정 후속을 취소한다. 후속 후보는 새로운 경기 사건이 아니라 이전 대화를 근거로 삼는다.

2단계에서는 내부 판정/저장 로직을 먼저 구현하고 자동 추첨·대사창 연결은 다음 콘텐츠 단계로 나눴다. 이후 아래32종 콘텐츠 단계에서 연결한다. [2단계 작업 기록](../work-logs/2026-11-14/2026-11-14-06-counseling-state.md).

## 상담32종·화면 연결 — 2026-11-14 승인·11-15 구현

실제 근거8종마다 일반3종/후속1종으로 총32종의 고유 대사·제목과 각 답변3개/반응을 구성한다. 일반 콘텐츠 ID는 상담/시드로 결정해 저장하고 후속 근거에는 후속 대화를 사용한다. 화면에는 효과 숫자 대신 질적 힌트만 보여준다. 응원·기대는 행복도+5/피로+2, 구체적 조언은+2/-3, 부담 낮추기는-2/-6이며 기존0~100 제한·경기 보정을 따른다. 기본 능력/경험치/자금은 바꾸지 않는다.

일반 대화의 조언은 정상 공식6경기 이후부터 같은 주제의 후속 후보를 예약한다. 출전/소속·쿨다운·확률을 모두 따르며 발생을 보장하지 않는다. 후속 대화는 새 후속을 예약하지 않는다. 확인되지 않은 연승·개별 실수·부상·KDA를 실제 기록처럼 대사로 만들지 않는다.

PC방 정규 시즌은 2026-11-09 사용자 결정으로 8팀 1회전·7주·팀당 매주 1경기/총 7경기·BO1(기존 MR12와 연장)이다. 승패 수로 순위를 정하고 같은 승패는 단판 순위 결정전으로 정한다. 승점·승자승·라운드 득실로 동률을 가르지 않는다. 일정·순위·저장·실제 공식 경기·주간 연결·동률 결정전 및 최종 정규 순위를 구현했다. 3팀 이상 동률은 해당 팀끼리 1회전으로 대결하고 재동률 팀들만 반복한다. PC방 플레이오프는 위 승인 규칙을 적용하며 PC방 이외의 승강 팀 수·상위 리그 실제 일정은 후속이다. 상대 구단은 기존 명단·능력과 경기 계산을 사용하며, 사용자 거래에 따른 자동 편성/방출을 유지한다. 초기 선수 데이터 목표는 가상 선수 600명이다. 선수 수와 팀 수는 독립적으로 관리하며 경쟁 게임의 이름·능력치·데이터를 복제하지 않는다.

## 선수

| 구분 | 요구 사항 |
|---|---|
| 기본 능력 | 에임·지능·체력, 각각 1~99 |
| 등급 | D, C, B, A, S, SS |
| 성장 | 동적 잠재력, 훈련, 나이에 따른 노화·은퇴 |
| 경기 적응 | 고유 특성, 팀워크. 고정 포지션은 제거하며 전술별 역할 배정은 후속 작업 |
| 일시 상태 | 컨디션·피로·사기·멘탈 |
| 경력 관리 | 계약·이적·스카우팅·유스 아카데미 |

초기 설계에서 미정이던 성장률·잠재력 공개 범위는 아래 최신 성장 규칙으로 확정했다. 등급 산식·등급 경계·은퇴 조건은 미정이며 체력 능력치와 피로, 경기 중 HP는 별도 개념이다.

최신 성장 규칙(2026-11-08 승인): 각 능력의 잠재력은 70~79 50%, 80~89 35%, 90~99 15%로 배정하고 현재 능력보다 낮으면 현재 능력으로 올린다. 선수별 성장 속도는 느림 0.8배 25%, 보통 1배 50%, 빠름 1.2배 25%다. 개인 훈련은 하루 경험치 8/10/12, 팀 훈련은 모드·승패·KDA를 반영한 총 경험치에 성장 배율을 곱해 반올림한 뒤 세 능력에 무작위 배분한다. 경험치 100마다 능력 +1이며 잠재력에 도달하면 그 능력에는 추가 경험치를 지급하지 않는다. 다른 능력으로 재추첨하지 않는다. 이벤트 상승도 잠재력에서 멈추며 하락 효과와 행복도의 경기 임시 보정은 유지한다. 영입 가격은 기존처럼 기본 능력만 사용한다. 명단의 성장 정보와 내 구단 경험치 표에서 잠재력·성장 속도를 공개한다. 기존 저장의 능력·경험치·계약·재정·과거 결과는 보존하고 최초 변환 이후 새 훈련부터 적용한다. 이하 기본 성장의 99 상한·동일 경험치 안내는 이 규칙이 대체한다.

피로·컨디션 규칙(2026-11-08 승인): 피로는 0~100·초기 0이며 컨디션은 100−피로다. 실제 진행한 하루마다 개인 훈련 +2, 팀 훈련 +3, 방송 +1, 휴식 -5를 적용한다. 기본 체력 80 이상이면 개인/팀 훈련 증가량이 하루 1 줄어든다. 당일 훈련으로 체력 80에 도달하면 다음 날부터 완화한다. 피로 0~24는 보정 없음, 25~49는 에임/지능 -1, 50~74는 -3, 75~100은 -5를 행복도 보정과 합산해 경기 능력을 1~99로 제한한다. 피로 효과는 기본 능력·잠재력·가격을 변경하지 않는다. 주간 일정에서 주전/후보의 실제 행동을 적용하며 중단/재개는 진행한 날만 처리한다. 팀 훈련 피로는 주간 참가 일정에서 반영하고 일반 관전·라운드 반복·현실 시간에는 누적하지 않는다. 진행 중 연습은 시작 당시 능력을 유지하고 새 연습부터 반영한다. 휴식의 행복도/장기 경험치 감소 규칙은 유지한다. 피로는 저장·이적 후 유지하고 구형 저장은 0으로 시작한다. 내 구단 경험치 표와 행동 선택 창에 현재 피로·컨디션·경기 보정을 표시한다.

사용자 승인으로 선수별 훈련·기본 성장을 구현했다. 내 구단 주전·후보는 에임·지능·체력·휴식 중 목표를 고르며 기본은 휴식이다. 성공한 하루 진행마다 선택 능력 경험치 +10, 경험치 100마다 능력 +1, 상한은 99다. 능력별 경험치는 목표 전환·방출·재영입·이적·저장 후 유지한다. 계약 만료 마지막 날은 훈련하며 이후 자유계약/AI 소속에서는 훈련하지 않는다. 날짜 진행이 차단되면 성장도 없다. 추가 훈련비 없이 기존 월급 조건을 유지한다. 에임·지능 성장은 새 맵 연습 교전에 반영하며 체력 성장은 능력·가격에 반영한다. 체력의 실제 경기 효과·잠재력·성장률 차등·피로·부상은 후속이다. 저장 v7에 목표·경험치를 보관하며 기존 저장은 능력·명단·계약·날짜·재정을 보존해 휴식/경험치 0으로 시작한다. [훈련 작업 기록](../work-logs/2026-11-08/2026-11-08-09-player-training.md)에서 사용자 확인을 진행한다.

최신 주간 일정 단계에서는 구단명 옆 1주 진행으로 7일을 하루씩 처리한다. 1주 진행을 누르면 선수별 행동 선택 창이 열리고 개인 세 능력 훈련·방송하기·팀 훈련·휴식 중 하나를 골라 해당 주간에 동일하게 적용한다. 선택 완료 후 날짜를 진행하며 취소/Esc는 적용하지 않는다. 요일별 선택은 없고 세 능력의 경험치는 주전/후보 명단 아래 별도 창에서 확인한다. 개인 경험치 10/일, 팀 훈련은 세 능력 각각 1/3 확률로 경험치 16/일, 방송은 경험치 없이 $30/일이다. 최대 능력으로 뽑힌 팀 훈련은 재추첨하지 않는다. 날짜 차단 시 이미 진행한 보상은 유지하고 남은 일수를 저장해 재개한다. 기존 계약/30일 급여·스폰서 정산을 그대로 적용한다. 맵 연습은 팀 연습으로 이름을 바꾸며 관전 반복으로 주간 보상을 지급하지 않는다. 저장 v8에 행동표·전용 난수·중단 일수를 보관한다. 행복도·반복 불이익·장기 휴식 경험치 감소·랜덤 이벤트는 이번 1번에 포함하지 않고 각각 2번/3번에서 구현한다. [주간 일정 기록](../work-logs/2026-11-08/2026-11-08-10-weekly-actions.md)에서 사용자 확인을 진행한다.

현재 팀 훈련 규칙은 위 초기 +16/일 지급을 대체한다. 주전 한 명이 선택하면 주전 5명이 함께 선택되고 후보는 개인 행동을 유지한다. ‘선택 완료 · 팀 훈련 진행’으로 주간 처리를 마친 뒤 팀 연습으로 이동한다. 기본 경험치는 이동 10·교전 25·폭탄 40·구매 50·MR12 120이며 승리 ×1.2·패배 ×0.8, 선수 KDA에 따라 ×0.8~1.2를 적용한다. 승패 없는 모드는 승패 보정이 없고 이동은 KDA 보정도 없다. 세 능력에 무작위 배분하며 상한 99를 유지한다. MR12는 최종 경기 종료, 구매/폭탄은 한 라운드 종료에 주당 1회 지급한다. 초기화·모드 변경·저장 복원으로 중복 지급하지 않는다. 종료 시 경기 내용·보상 창과 오른쪽 아래 내 구단 버튼을 표시한다. 대기 중 주전 변경/방출과 다음 주 진행을 막고 ‘팀 훈련 이어하기’로 재진입한다. 현재 저장은 v9이며 자세한 산식은 [팀 훈련 기록](../work-logs/2026-11-08/2026-11-08-11-team-training.md)을 따른다.

## 전술과 경기

최신 팀 연습 확대 화면에서도 라운드 시작·스킵·관전 속도·장비 구매·경기 내용을 사용한다. 패널 버튼은 상단 공용 툴바에 남고 패널을 닫으면 지도가 넓어진다. 확대/복귀는 경기·구매·기록을 초기화하지 않는다. 경기 구매 표기는 장비 구매로 변경했다. [확대 조작 작업](../work-logs/2026-11-08/2026-11-08-18-expanded-match-controls.md)에서 실제 화면 확인을 진행한다.

현재 팀 연습은 시작·스킵·타임아웃·점수와 지도를 화면 높이에 맞추고 옆 패널에서 수동/자동 전략·구매·경기 내용을 전환한다. 구매는 기본으로 열며 긴 기록은 패널 안에서 스크롤해 매 라운드 페이지 위아래를 오가지 않게 한다. 규칙·보상 안내·선수 상세는 접었다 펼친다. 작은 창은 지도/패널을 위아래로 나누고 지도 비율을 유지한다. [배치 작업 기록](../work-logs/2026-11-08/2026-11-08-16-practice-viewport.md)에서 실제 창 크기별 사용자 확인을 진행한다.

행복도·반복 행동·장기 휴식은 육성 2번에서 구현했다. 소속 선수는 행복도 70부터 시작하며 범위는 0~100이다. 훈련/팀 훈련 첫 주는 유지, 방송 첫 주는 +7이다. 같은 비휴식 행동 2주째 -7, 3주째부터 매주 -14이며 에임·지능·체력 훈련은 서로 다른 행동이다. 휴식 첫 주는 행복도 +14, 2주째 +7·세 능력 경험치 각각 -14, 3주째부터 행복도 유지·각 경험치 -21이다. 경험치는 0 아래로 내려가지 않으며 기본 능력치는 유지한다. 실제 진행 기간만 계산하고 행동 선택만 바꿔 반복 기록을 지울 수 없다. 저장/복원·주차 전환 후에도 유지하며 기존 저장은 과거를 소급하지 않는다.

행복도에 따라 새 연습 경기의 세 능력을 90 이상 +3 / 75~89 +1 / 45~74 0 / 25~44 -2 / 24 이하 -4로 임시 보정하고 1~99로 제한한다. 기본 능력·영입 가격·성장은 유지한다. 체력의 실제 경기 효과는 기존 구현을 따른다. 방출/재영입은 행복도를 초기화하지 않으며 소속 공백은 연속 행동을 끊는다. 일반 선수 목록에는 행복도를 노출하지 않고 내 구단 능력/행동 패널에서 확인한다. 상세 사항은 [행복도 기록](../work-logs/2026-11-08/2026-11-08-14-player-happiness.md)을 따른다. 3번 랜덤 이벤트는 아래 구단 경영 절의 최신 규칙으로 구현했으며 2·3번 통합 확인을 진행한다.



5대5 전술형 FPS, MR12, 정규 13라운드 선취, 12:12 시 연장전이다. 사용자 승인으로 정규 12라운드 종료 후 진영 교대와 전원 $800·권총 초기화를 적용한다. 연장은 한 묶음 최대 6라운드 중 4승 선취이고 3:3이면 반복한다. 연장 시작과 이후 3라운드마다 진영을 교대하며 전원 $10,000·권총으로 초기화한다. 팀 이름·색과 누적 점수는 유지하고 진영만 바꾼다.

맵은 경기 시작 전에 공개하며 목표 초기 맵은 독자 설계 3개다. 현재 중계소·화물 창고·연구 시설 3개에서 이동·벽 충돌·시야·교전·폭탄·구매·MR12와 반복 연장을 지원한다. 화물 창고는 긴 중앙 통로·선반/화물 엄폐·외곽 우회로를 가진다. 연습 맵 선택을 바꾸면 새 경기로 시작하고 점수·경기 자금·누적 기록·수동 경로를 초기화한다. 공격 경로·수비 배치·지원 위치는 맵별로 지정하고 공통 경기 규칙을 사용한다. 화물 창고의 사용자 확인은 [두 번째 맵 작업 기록](../work-logs/2026-11-07/2026-11-07-21-second-map.md), 기존 경기의 통합 확인은 [MR12 기록](../work-logs/2026-11-07/2026-11-07-09-mr12-match.md)에서 관리한다. 실제 상태로 승패를 계산하며 결과는 화면 안에서만 유지한다. 연구 시설은 칸막이로 나눈 짧은 통로와 상·중·하 연결 구역을 가진다. 사용자 확인은 [연구 시설 작업 기록](../work-logs/2026-11-07/2026-11-07-22-research-map.md)에서 진행하며 구단 전적·시즌·저장 반영은 후속 범위다.

공격은 집중 진입과 분산 진입을 구매 단계에서 선택한다. 명단 1~2번은 선두, 3번은 최초 폭탄 담당, 4~5번은 지원이다. 집중 진입은 중앙 길목으로, 분산 진입의 지원 2명은 A 위쪽/B 아래쪽 외곽으로 접근해 같은 사이트를 공략한다. 폭탄 낙하 시 가까운 생존 공격수 한 명에게 회수 임무를 배정하고 나머지는 기존 임무를 이어간다. 설치 후에는 선수별 담당 진입로에서 좁게 순찰·경계한다. 상대는 집중 진입을 사용하며 선택은 팀에 귀속되어 공수 교대 후 적용한다. 능력 기반 역할 최적화·다양한 상대 전술 선택은 후속 범위다. 수비 패배 편향에 대한 사용자 보고 후 서로 사격 가능한 배치·좁은 순찰·이동과 경계 시선 분리·관측한 적 수에 따른 지원·아군 합류 후퇴를 보강했다. 양 진영 모두 유효 표적을 유지하고 실제 피격 방향을 확인하도록 했다. 동일 능력·무기의 독립 라운드에서 수비 승리 빈도가 개선됐으나 전술·사이트·무기별 편차는 남아 있으며 최종 밸런스는 계속 검증한다.

이동, 시야, 엄폐, 사격, 명중, 피해, 사망, 무기 구매·라운드 경제, 폭탄 설치·해체가 실제 상태를 바꾸고 이 상태에서 승패가 결정되어야 한다. 승자를 먼저 뽑고 장면을 꾸미는 구현은 금지한다. 구단 운영 자금과 선수별 경기 구매 자금은 서로 다른 회계다.

생존 선수는 팀과 무관하게 반지름 10의 몸체 간격을 유지하며 이동한다. 앞 선수가 길을 막으면 우회·양보하거나 대기하고 사망자는 통행을 막지 않는다. 같은 일반 경유점/목적지는 겹치지 않는 인접 위치에서 도착할 수 있으나 폭탄 설치·회수·해체의 실제 위치 조건은 유지한다. 이동 변경에 따른 전술별 승률은 별도 밸런스 확인 대상이다.

초기 시야 실험에서 공격 90도/200·수비 120도/260을 적용했으며, 장비 확장 후 2026-11-09 사용자 요청에 따른 AI 종합 조사로 공격 100도/220·수비 110도/240으로 조정했다. 매 라운드 현재 진영에 맞게 적용하고 설치 후에도 유지한다. 과거 원자료는 [시야 실험 보고서](DEFENSE_EXPERIMENT.md), 최신 근거·관측 공유·장비 회피·섬광 강도·투척물 반경 조정은 [AI 조사 보고서](AI_AUDIT.md)를 따른다. 확정된 최종 밸런스는 아니며 새 맵·장비·전술 추가 시 다시 검증한다.

선수별 K/D/A·피해량, 하이라이트·통계를 기록한다. 현재 MR12 맵 연습은 해당 경기의 모든 라운드 K/D/A·피해를 진행 중부터 누적 표시하고 후반전·연장·최종 경기 종료까지 유지한다. 새 경기 초기화나 화면 재진입은 새 기록으로 시작하며 구단 통산 기록·저장 반영은 후속 범위다. 관전은 1배·2배·4배·스킵을 제공하되 배속과 스킵이 결과를 바꾸지 않아야 한다. 탑다운 2D 지도에서 팀 색상별 원형 선수, 총알 궤적, 시야, 엄폐, 사망 위치를 구분한다. 지도와 충돌·시야 판정은 같은 좌표 데이터를 사용한다.
