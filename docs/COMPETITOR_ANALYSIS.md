- 조사일: 2026-11-07 (Asia/Seoul)
- 상태: 공개 화면 및 로그인 후 접근 가능한 화면 조사 반영, 사용자 검토 승인 (2026-11-07). 온보딩·영입·해금이 필요한 기능은 미검증으로 남긴다.
- 도구: 연결된 Chrome MCP. 실제 탭 진입·접근성 스냅샷·화면 이미지·일부 조작으로 확인했다.

## 근거 구분과 한계

- **직접 확인**: 이번 브라우저에서 보거나 조작한 화면. 버튼을 보았다는 것과 효과를 검증한 것은 구분한다.
- **공식 설명**: 해당 서비스의 공개 소개·매뉴얼에 적힌 기능. 실제 작동 검증을 의미하지 않는다.
- **확인 불가/미검증**: 로그인 필요, 이번 범위에서 조작하지 않음, 내부 계산을 관찰할 수 없음.
- **적용 제안**: 우리 게임을 위한 판단이며 경쟁 게임의 결함이나 구현 사실을 단정하지 않는다.

코드·에셋·선수 데이터는 복제하지 않았다. 공개되지 않은 서버 내부에는 접근하지 않았다. 로그인 화면의 개인 정보는 기록하지 않으며 인증은 사용자가 직접 수행한다. 공개 소개만으로 내부 시뮬레이션이 실제로 어떻게 계산되는지 입증할 수 없다.

## CPL Manager

근거: [공식 소개](https://www.cplmanager.com/), [공개 경기 990831](https://www.cplmanager.com/cpl/live/990831), [로그인 진입점](https://www.cplmanager.com/login).

### 직접 확인

공개 경기 리플레이가 로그인 없이 열린다. 상단 양 팀 점수·라운드·시계, 중앙 탑다운 지도, 좌우 선수별 HP·잔액·무기·탄약·장비가 보인다. 팀 색상의 원형 선수와 이름이 지도에 표시되고 시간 경과에 따라 라운드·점수가 변한다.

0.5/1/2/4배 버튼, 라운드별 이동 버튼, 타임라인과 킬 이벤트 버튼을 확인했다. 4배 버튼을 눌러 재생 상태를 확인했고 12라운드 버튼 클릭 후 Round 12와 해당 점수로 바뀌는 것을 확인했다. 배속의 정확한 시간 비율까지 측정하지는 않았다. Viewer settings를 열어 선수 특성 배지 표시 옵션을 확인했다. 소개 화면에는 전술 편집 이미지와 스폰서 계약 예시가 있다.

### 공식 설명

영입 경매·아카데미·잠재력 탐색·훈련·노화, 맵·진영·구매별 전술, 선수별 경로·시선, 경기별 피해·KAST·생존·트레이드·첫 교전 기록을 소개한다. 급여·이적·훈련 비용과 스폰서·미션, 리그·래더·챔피언십을 설명한다. 이는 소개 내용 확인이며 구단 운영·계약 체결·훈련 효과를 직접 검증한 결과는 아니다.

### 미확인 및 적용 판단

로그인 후 선수·훈련·공개 유스·이적 이력·경기 통계를 추가 확인했다. 아래 추가 조사에 근거를 기록한다. 이적 입찰·계약 체결·훈련 배정·유스 영입·전술 저장·재정 운영의 실제 효과는 미검증이다. 공개 리플레이만으로 엔진 내부 계산을 확인할 수 없다.

장점으로 참고할 요소는 라운드별 탐색, 경제와 장비를 함께 보여주는 선수 카드, 경기 결과와 전술 검토의 연결이다. 관찰한 화면에서는 선수들이 가까이 있을 때 이름이 겹친다. 우리 게임은 번호·선택 강조·정보 표시 전환을 고려하고 선수 카드가 지도 면적을 과도하게 줄이지 않도록 한다. 이는 화면 관찰에서 도출한 개선 제안이다.

### 로그인 후 추가 조사

사용자가 2026-11-07 로그인 완료를 알린 뒤 조사했다. [Getting Started](https://www.cplmanager.com/cpl/getting-started)는 7단계 진행률과 선수 이름·선발·훈련·스트리밍 과제를 표시한다. 사무실·전술·영입·경쟁·유스 단계에는 레벨 해금 조건이 보였다. 과제 수행이나 보상 수령은 하지 않았다.

[훈련실](https://www.cplmanager.com/cpl/team/training)은 선수 배정 슬롯과 훈련실 그림을 표시한다. [날짜별 보고서](https://www.cplmanager.com/cpl/team/training/report)는 해당 날짜의 훈련·경험 기록 없음 상태였다. 따라서 성장 결과는 검증하지 못했다.

## Gladi eSports Manager

근거: [공식 소개와 공개 화면 이미지](https://www.gladi.tv/), [로그인 진입점](https://www.gladi.tv/sign-in).

### 직접 확인

공개 사이트에서 경기 화면 이미지 확대 버튼을 눌렀다. 확대된 **정지 이미지**에 팀별 원형 선수, 이름, 사망 표시처럼 보이는 X, 구역 이름, 연막처럼 보이는 원형 효과, 우측 이벤트 피드가 보인다. X와 원형 효과의 실제 판정 의미는 조작으로 검증하지 않았다. 이벤트 텍스트에는 킬·트레이드·투척·구매 상황이 표시된다. 우측에 라운드 승률 표시도 보인다.

실제 라이브 경기를 관전한 것은 아니다. 최초에는 로그인 폼을 확인했고, 사용자 인증·구단 생성 후에는 아래 시장·선수 상세를 추가 조사했다. 경기 조작과 전술 편집은 현 계정의 영입 선행 조건 때문에 확인하지 못했다.

### 공식 설명

라이브 2D 레이더, 라운드 시간·승률·장비 가치·이벤트 피드, 맵당 최대 3회 전술 타임아웃을 소개한다. 전술은 맵별 역할과 공격성·유틸리티·회전 속도·경제 규율 등의 슬라이더를 설명한다. 계약·급여·조직력·체력·훈련, 자유계약·구단 간 이적·스카우팅, 일일 컵·주간 리그·초청 대회를 소개한다.

### 미확인 및 적용 판단

실제 경기의 정지·변경 적용 시점·경제 결과는 미검증이다. 사용자 경로 편집이 가능한지도 소개만으로 단정하지 않는다. 승률 수치의 계산 근거는 확인하지 않았다. 로그인 후 확인한 시장·온보딩과 남은 제약은 아래에 기록한다.

지도 옆에 원인을 읽을 수 있는 이벤트 피드를 배치하는 점을 참고한다. 우리 게임은 설치·해체·사망·구매를 시간과 라운드별로 연결하는 안을 추천한다. 검증되지 않은 승률 숫자를 핵심 UI로 선행 도입하지 않는다. 정지 이미지에서 보이는 정보 구조를 장점으로 평가한 것이며 실제 관전 사용성을 평가한 결과는 아니다.

### 로그인·구단 생성 후 추가 조사

사용자가 두 사이트 로그인 완료와 Gladi 구단 생성 완료를 알렸다. 최초 [온보딩](https://www.gladi.tv/onboarding)에는 관리자명·구단명·지역·배경 선택, $100,000 시작 예산, 5명 영입 후 필수 연습 경기 안내가 있었다. 구단 생성은 사용자가 직접 수행했다.

이후 [구단 화면](https://www.gladi.tv/club)에서 생성된 구단과 선수 0/5 영입 상태를 확인했다. 자유계약 선수 5명을 영입해야 연습 경기가 열린다는 안내가 보였고, 구단 순위 링크도 이 상태에서는 구단 화면으로 돌아왔다. 조사 과정에서 선수 영입·비용 지출은 하지 않았다.

[자유계약 시장](https://www.gladi.tv/market?tab=free)에는 역할 필터(Entry/AWP/Support/IGL/Lurk), 최대 가격, 나이·전체 평가·세부 능력·가격·주급 정렬, 스카우팅·영입 버튼이 보였다. 일부 능력은 ??, 전체 평가는 근삿값으로 표시된다. [구단 소속 매물](https://www.gladi.tv/market?tab=listed)에는 판매 구단과 요구 가격이 표시되고, 예산을 초과한 매물은 Over budget 상태로 동작 버튼이 비활성화되어 있었다. 필터·정렬 항목의 존재를 확인했으며 계약·협상 성사나 예산 차감 효과는 검증하지 않았다.

[선수 상세 예시](https://www.gladi.tv/players/cmvb1uewp003rv5t44qwtewib)에는 나이·역할·가치·잠재력·능력, 경기 기록·ADR·KAST·경기 추세 영역, 맵 숙련도가 보였다. 해당 선수의 경기 이력은 비어 있었다. 유료 스카우팅 버튼과, 소속 구단만 알 수 있는 체력·사기·조직력은 스카우팅으로 공개되지 않는다는 안내도 확인했다. 유료 스카우팅은 실행하지 않았다.

이 선수 상세의 Development와 Ownership 구역은 Coming Soon으로 표시되며 성장 추적과 계약·주급 상세가 아직 제공되지 않는다고 안내한다. 시장에는 주급과 영입 버튼이 있으므로 **선수 상세 구역의 미제공을 게임 전체 계약 기능 미구현으로 확대 해석하지 않는다.** 공개 소개와 실제 화면 사이의 기능별 구현 상태 차이를 주의해야 한다.

경기·전술·타임아웃·실시간 이벤트는 5인 영입 선행 조건 때문에 여전히 직접 검증하지 못했다. 따라서 Gladi 2D 관전 근거는 공개 정지 이미지와 소개 설명으로 유지한다. 우리 게임에는 시장의 가격·주급 동시 표시, 추정 능력과 확정 능력의 구분, 예산 초과 사유 표시를 후속 시장 단계에서 참고할 것을 제안한다.

### 직접 확인

계정 없이 커리어 목록에 진입했다. 새 커리어·저장 가져오기·커뮤니티 저장 메뉴와 저장된 커리어가 없는 초기 화면을 확인했다. 커리어 생성·저장 왕복은 수행하지 않았다.

Exhibition에서 Tactical Shooter를 선택하고 맵 Sands를 선택했다. 맵 선택 목록에는 Sands·Oasis·Ruins가 있었다. 한 팀을 User로 전환하고 연습 경기를 시작했다. 경기 화면에 중앙 지도·선수 위치, 점수·시계·라운드, 좌우 선수 카드·역할·잔액·K/D/A·첫 교전·클러치 지표가 표시된다. 경제 Auto/Eco/Half Buy/Full Buy와 구매 상황별 전략 선택 버튼이 보인다.

Eco 선택 후 Play를 눌러 타이머 진행과 지도 위 선수 위치를 확인했다. Eco 클릭이 모든 선수 구매에 어떻게 반영되는지는 정량 검증하지 않았다. 경기에는 재생/일시정지·Sim Round·속도·카메라·타임아웃 예약 버튼이 있다. 타임아웃 예약 및 Sim Round 클릭 후 확인 대화상자가 나타났고, 다음 라운드 준비와 코치 전술 지식에 따른 능력 보정 설명을 확인했다. 확정 후 효과·완전한 경기 결과까지 검증한 것은 아니다.

Customization에는 기본 프로필이 읽기 전용이며 편집하려면 복제하라는 안내가 있다. 원본 데이터·에셋 복제를 피하기 위해 템플릿 복제는 수행하지 않았다. 전술 편집기의 경로 저장·재실행은 직접 검증하지 않았다. 첫 공개 페이지의 Play 링크 클릭은 시간 초과했으나 표시된 dashboard 주소로 직접 이동해 정상 접근했다.

### 공식 설명

소개는 라운드 전술 편집과 틱 기반 시뮬레이션, 계약·이적·재정·스폰서·대회를 설명한다. 시작 매뉴얼은 그리드 이동, 시야각·기억, 유틸리티 영향, 포지션·무기 숙련 보정, 사기 등을 설명한다. 이는 공식 설명이지 내부 계산 검증이 아니다.

시작 매뉴얼은 완전한 커리어를 장래 목표로 표현하지만 현재 공개 사이트와 대시보드는 커리어 진입을 제공한다. 안내 간 시점 차이가 있을 수 있으므로 현 버전에서 모든 경영 기능이 구현됐다고 단정하지 않는다.

### 적용 판단

계정 없이 바로 연습할 수 있는 진입, 구매 단계와 전술 연결, 경기 카드의 통계 표시는 참고할 가치가 있다. 관찰한 화면에서는 지도 가까이 모인 선수 이름·아이콘이 겹치고 카드가 세로 공간을 많이 사용한다. 우리 게임은 확대·선택 정보와 지도 가독성을 우선하고, 첫 구현에는 선수 경력 모드나 프로필 편집 같은 별도 시스템을 추가하지 않는다.

## 조사 범위와 남은 한계

사용자 인증·Gladi 구단 생성 후 접근 가능한 화면의 조사는 반영했다. 계정 진행 변경 없이 조사했으며 선수 영입·방출·입찰·훈련 배정·스카우팅 결제·경기 등록은 수행하지 않았다. 화면 열람에 따른 일반적인 방문 기록 등은 서비스에서 남을 수 있다.

CPL 초보자 과정 진행과 Gladi 5인 영입을 수행해야 추가로 확인할 수 있는 운영·경기 기능은 미검증이다. 이는 미확인 기능 목록이며 이번 초기 설계를 위해 사용자의 게임 진행을 필수 작업으로 추가하지 않는다. 사용자가 추후 해당 과정을 진행한 뒤 심층 조사를 요청하면 이 문서를 보완한다. 모든 경쟁작의 내부 엔진 정확성과 공개되지 않은 서버 계산은 검증 대상에 포함하지 않았다.
