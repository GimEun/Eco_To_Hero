## 확인한 원인과 수정

1. **장비 조건에서 진영 편향이 커졌다.** 같은 능력으로 장비를 분리한 288라운드에서 소총만 사용한 조건의 수비 승률은 49.0%, 소총+방탄복은 53.1%, 소총+투척물은 97.9%였다. 투척물과 AI 대응이 주원인이었다.
2. **투척이 총보다 즉시 반응했다.** 투척 반응 시간을 두어 총으로 먼저 대응할 기회를 만들었다. 반응에는 지능과 선수별 차이를 반영한다.
3. **중복 방지가 상대 팀까지 묶었다.** 같은 지역에 날아가는 같은 종류의 장비를 팀 구분 없이 검사하던 것을 내 팀 중복만 피하도록 수정했다.
4. **공격팀의 관측 공유와 시선 유지가 부족했다.** 동료가 실제로 본 적의 마지막 위치를 공유하고, 현재 교전 중인 유효 표적을 우선한다. 보이지 않는 상대의 새 위치는 알지 못하며 기록은 5초 후 만료한다. 배치 완료·설치 후 경계와 수비 후퇴 지점에서도 유효한 교전 시선을 유지한다.
5. **섬광 효과가 지나치게 일률적이었다.** 거리·방향에 따라 강도와 지속 시간이 달라지도록 했다. 약한 섬광으로 강한 효과를 연장하지 않는다. 적보다 많은 아군을 눈멀게 하는 자동 투척은 피한다.
6. **날아오는 장비에 대응하지 않았다.** 실제로 보이는 수류탄을 판단해 기존 이동 목표를 보존하며 회피한다. 보이는 섬광에는 반응 시간을 두고 시선을 돌린다. 보이지 않는 장비에 즉시 반응하는 방식은 사용하지 않는다.
7. **회피 후 도착 상태가 남는 버그를 확대 검사에서 찾았다.** 도착한 선수가 회피로 자리를 벗어나면 도착 상태와 밀집 목표를 해제하고 기존 목적지로 돌아가도록 수정했다. 폭탄 운반자가 설치 위치를 벗어난 채 멈추는 사례를 회귀 검사에 추가했다.

### 새로 구성 재현한 미관측 정보 사용

- 위치: `src/simulation/throwables.js:104`의 `exposed`는 폭발점 근처의 **현재 전체 선수 좌표**에서 적/아군 인원을 계산한다. 벽 시야선은 검사하지만 투척팀의 실제 관측·공유 정보 여부를 확인하지 않는다. 이 수가 106행의 섬광 투척 허용 여부에 쓰인다.
- 구성 장면: 벽 없는 20×20·타일 40 맵. 투척수 (100,100), 아군 (220,110)/(220,90), 보이는 적 (220,100). 숨은 적 2명은 가까운 경우 (260,170)/(260,30), 먼 경우 (400,350)/(400,300)다. 관측 시야각은 π/8, 시야거리 500, 투척수는 오른쪽·나머지 아군은 왼쪽을 본다. tick 100·seed 1·intelligence 50·기존 표적 접촉 tick 0·보유 섬광 1개로 `autoThrow`를 호출했다.
- 양 조건에서 투척수는 같은 적 1명만 보고 다른 아군은 아무 적도 보지 못했다. 관측 ID 목록이 같음을 검사했다. **숨은 적이 멀면 투척 0회, 가깝면 1회**로 달랐다. 숨은 현재 위치의 변화가 미관측 상태에서 의사결정에 영향을 준 것이다.
- 메모리상 구성 검사이며 게임 파일을 수정하거나 자연 경기 발생 빈도를 측정한 것은 아니다. 섬광 효과 계산이 실제 좌표로 피격자를 정하는 것은 정상인 반면, 투척 결정을 내리는 단계의 정보 사용은 별도 문제다. 전체 AI가 모든 숨은 위치를 추적한다고 확대 해석하지 않는다.
- 후속 검증 기준 제안: 관측 이력이 같고 미관측 적의 현재 위치만 다른 두 상태에서, 해당 정보에 의존하지 않아야 하는 의사결정이 동일해야 한다. 시야·피격·공개 생존 인원 등 실제 획득 정보가 달라지는 조건은 별도로 둔다.

### 프롬프트의 전술 목록을 행동으로 옮기는 방법 — 제안

| Default | 여러 구역 정보 수집, 관측/시간에 따라 최종 사이트 결정, 미관측을 안전으로 단정하지 않음 |

### 권장 요청 분할·검증 순서

전면 개선을 한 작업 문서로 구현/승인하기에는 크다. **전투 AI는 아래 7개 요청으로 나누는 안**을 권장하며, 실제 착수·범위/번호 재편은 사용자 결정 후 진행한다. 기존 12개 목록을 자동 변경하지 않는다.

1. 정보 공정성·연막 대응: 획득 정보/위험 추정 구분, 섬광의 미관측 정보 사용, 만료·사망·라운드 초기화, 마감 임박의 목표 행동.
2. 전술 역할 배정: 기존 12번의 설계·화면/자동·수동·저장 범위. 출전 순서와 전술 역할 분리.
3. 팀 공동 진입·트레이드·유틸 연계: 기존 execute/split에 집결/대기 상한/지원/섬광 후 진입을 먼저 연결. 새 전술명 추가보다 기존 전술의 행동 완성 우선.
4. 공격 운영 확장: 정보 수집 Default·Rush부터, 이후 Fake/Contact/Lurk/Late의 필요 전제와 단위를 추가로 확정. 한 번에 모든 항목 구현을 요구하지 않는다.
5. 수비 협동: 기존 standard/forward·해체·장비 보존 기반의 교차 사격·합류 Retake·조건부 Rotate/Stack/Passive.
6. 팀 경제: Full/Force/Eco/Half의 현재/다음 라운드 예산과 실제 장비, 기존 Save 연결. 게임 고유 가격/보상/후반전 초기화에 맞춤.
7. 상대 패턴 대응: 실제 관측 라운드의 거점/시간/경로 기록과 불확실한 추정. 기존 리그별 전환 기준과 충돌하지 않도록 적용 시점/제한을 먼저 확정.

이후 4번 주간 성장 연결을 고려해 1번 최종 밸런스 → 3번 전체 리그 난이도를 검증하는 순서를 권장한다. 상담·보상·플레이오프 등의 별도 작업을 삭제하거나 모두 전투 AI의 선행 조건으로 묶지 않는다.

- 행동 검증: 같은 정보에서 같은 판단, 미관측을 안전으로 단정하지 않음, 팀 진입 시간차/후속 교전 가능 여부/아군 섬광/역할 수행·목표 완료로 기능을 확인한다. 승률만으로 정상 작동을 판정하지 않는다.
